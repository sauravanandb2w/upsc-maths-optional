§ Proofs — Root Finding

Newton-Raphson: Quadratic Convergence — Proof

If \(f(r)=0\), \(f'(r)\ne0\), and \(f''\) is bounded near \(r\), then NR iteration \(x_{n+1}=x_n-\dfrac{f(x_n)}{f'(x_n)}\) converges quadratically: \(e_{n+1}\approx\dfrac{f''(r)}{2f'(r)}e_n^2\) where \(e_n=x_n-r\).

Proof

Step 1 Taylor expand \(f\) around \(r\): \(f(x_n)=f(r)+e_nf'(r)+\dfrac{e_n^2}{2}f''(\xi)\) for some \(\xi\) between \(r\) and \(x_n\). Since \(f(r)=0\): \(f(x_n)=e_nf'(r)+\dfrac{e_n^2}{2}f''(\xi)\).

Step 2 Similarly: \(f'(x_n)=f'(r)+e_nf''(\eta)\) for some \(\eta\).

Step 3 \(e_{n+1}=x_{n+1}-r=x_n-\dfrac{f(x_n)}{f'(x_n)}-r=e_n-\dfrac{e_nf'(r)+e_n^2f''(\xi)/2}{f'(r)+e_nf''(\eta)}=\dfrac{e_n^2f''(\xi)/2}{f'(r)+e_nf''(\eta)}\approx\dfrac{f''(r)}{2f'(r)}e_n^2\) (for small \(e_n\)). \(\blacksquare\)

Bisection Method: Convergence — Proof

If \(f\) is continuous on \([a,b]\) and \(f(a)f(b)<0\), bisection converges with \(|e_n|\le\dfrac{b-a}{2^n}\).

Proof

After \(n\) steps, the interval containing the root has length \((b-a)/2^n\). The midpoint \(x_n\) satisfies \(|x_n-r|\le(b-a)/2^{n+1}\). As \(n\to\infty\), \(|e_n|\to0\) (linear convergence with rate 1/2). \(\blacksquare\)

§ Proofs — Interpolation

Newton's Forward Difference Formula — Derivation

\(y(x)=y_0+s\Delta y_0+\dfrac{s(s-1)}{2!}\Delta^2y_0+\dfrac{s(s-1)(s-2)}{3!}\Delta^3y_0+\cdots\) where \(s=(x-x_0)/h\).

Derivation

Use the shift operator \(E=1+\Delta\). At \(x=x_0+sh\): \(y(x)=E^sy_0=(1+\Delta)^sy_0\). Expand binomially: \(y=\left(1+s\Delta+\binom{s}{2}\Delta^2+\binom{s}{3}\Delta^3+\cdots\right)y_0=y_0+s\Delta y_0+\dfrac{s(s-1)}{2!}\Delta^2y_0+\cdots\). \(\blacksquare\)

Lagrange Interpolation Error — Proof

Error in Lagrange interpolation through \((n+1)\) points: \(E(x)=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}\prod_{i=0}^n(x-x_i)\) for some \(\xi\) in the interval.

Proof

Let \(\omega(x)=\prod_{i=0}^n(x-x_i)\). Define \(g(t)=f(t)-P_n(t)-\lambda\omega(t)\) where \(\lambda\) is chosen so that \(g(x)=0\). Then \(g\) has \((n+2)\) zeros: \(x_0,x_1,\ldots,x_n,x\). By Rolle's theorem applied \((n+1)\) times: \(g^{(n+1)}(\xi)=0\) for some \(\xi\). So \(f^{(n+1)}(\xi)-(n+1)!\lambda=0\Rightarrow\lambda=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}\). Since \(g(x)=f(x)-P_n(x)-\lambda\omega(x)=0\): \(f(x)-P_n(x)=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}\omega(x)\). \(\blacksquare\)

§ Proofs — Numerical Integration

Simpson's 1/3 Rule — Derivation

\(\int_a^b f(x)\,dx\approx\dfrac{h}{3}[f(x_0)+4f(x_1)+f(x_2)]\) where \(h=(b-a)/2\). Error: \(-\dfrac{h^5}{90}f^{(4)}(\xi)\).

Derivation

Step 1 Fit quadratic through \((x_0,f_0),(x_1,f_1),(x_2,f_2)\) with \(x_0=a,x_1=(a+b)/2,x_2=b\): \(P_2(x)=\dfrac{(x-x_1)(x-x_2)}{(x_0-x_1)(x_0-x_2)}f_0+\dfrac{(x-x_0)(x-x_2)}{(x_1-x_0)(x_1-x_2)}f_1+\dfrac{(x-x_0)(x-x_1)}{(x_2-x_0)(x_2-x_1)}f_2\).

Step 2 Integrate: with \(s=(x-x_1)/h\), \(\int_{-1}^1(s^2-s^2)ds... \) Using \(\int_{x_0}^{x_2}P_2\,dx=h\!\int_{-1}^1\!\left[\dfrac{s(s-1)}{2}f_0-\dfrac{s^2-1}{1}f_1+\dfrac{s(s+1)}{2}f_2\right]ds\). \(\int_{-1}^1s(s-1)ds=2/3-0\)... Computing each coefficient: \(f_0:\int_{-1}^1\frac{s(s-1)}{2}ds=\frac{1}{2}\cdot\frac{2}{3}=\frac{1}{3}\). \(f_1:\int_{-1}^1(1-s^2)ds=\frac{4}{3}\). \(f_2:\int_{-1}^1\frac{s(s+1)}{2}ds=\frac{1}{3}\). Total: \(h(f_0/3+4f_1/3+f_2/3)=\frac{h}{3}(f_0+4f_1+f_2)\). \(\blacksquare\)

Composite Rules & Error Summary
  • Trapezoidal (composite, \(n\) subintervals): \(\dfrac{h}{2}[y_0+2(y_1+\cdots+y_{n-1})+y_n]\), error \(O(h^2)\)
  • Simpson's 1/3 (composite, \(n\) even): \(\dfrac{h}{3}[y_0+4y_1+2y_2+4y_3+\cdots+4y_{n-1}+y_n]\), error \(O(h^4)\)
  • Simpson's 3/8 (multiple of 3 subintervals): \(\dfrac{3h}{8}[y_0+3y_1+3y_2+2y_3+3y_4+\cdots+y_n]\)

§ Proofs — Numerical ODEs

RK4 Algorithm — Derivation Idea

For \(y'=f(x,y),y(x_0)=y_0\). RK4 step: \(y_{n+1}=y_n+\dfrac{h}{6}(k_1+2k_2+2k_3+k_4)\) where \(k_1=f(x_n,y_n),k_2=f(x_n+h/2,y_n+hk_1/2),k_3=f(x_n+h/2,y_n+hk_2/2),k_4=f(x_n+h,y_n+hk_3)\).

Derivation (Taylor expansion matching)

The exact solution satisfies \(y(x_{n+1})=y(x_n)+hy'(x_n)+\dfrac{h^2}{2}y''(x_n)+\dfrac{h^3}{6}y'''(x_n)+\dfrac{h^4}{24}y^{(4)}(x_n)+O(h^5)\). The RK4 coefficients are chosen so that the weighted combination \(\frac{h}{6}(k_1+2k_2+2k_3+k_4)\) matches these Taylor terms up to \(O(h^4)\). The weights \(1,2,2,1\) (from Simpson's 1/3 rule applied to slope evaluation) ensure 4th-order accuracy. Local truncation error: \(O(h^5)\), global error: \(O(h^4)\). \(\blacksquare\)

PYQ 2024 — Newton-Raphson Iteration

Find \(\sqrt{3}\) using Newton-Raphson starting from \(x_0=2\). Perform 2 iterations.

Solution

Set \(f(x)=x^2-3\). \(f'(x)=2x\). NR: \(x_{n+1}=x_n-\dfrac{x_n^2-3}{2x_n}=\dfrac{x_n^2+3}{2x_n}\).

Iter 1: \(x_1=\dfrac{4+3}{4}=\dfrac{7}{4}=1.75\).

Iter 2: \(x_2=\dfrac{(7/4)^2+3}{2\cdot7/4}=\dfrac{49/16+48/16}{7/2}=\dfrac{97/16}{7/2}=\dfrac{97}{56}\approx1.73214\). True value: \(\sqrt{3}\approx1.73205\). Error \(\approx0.00009\). \(\blacksquare\)

PYQ 2022 — N-R for Transcendental Equation

Find the root of \(xe^x=1\) near \(x_0=0.5\) using 2 iterations of Newton-Raphson.

Solution

\(f(x)=xe^x-1,f'(x)=e^x+xe^x=(1+x)e^x\). \(x_1=0.5-\dfrac{0.5e^{0.5}-1}{1.5e^{0.5}}=0.5-\dfrac{0.5\times1.6487-1}{1.5\times1.6487}=0.5-\dfrac{0.8244-1}{2.4731}=0.5-\dfrac{-0.1756}{2.4731}=0.5+0.0710=0.5710\). \(x_2\approx0.5671\) (converges to \(0.5671\)). \(\blacksquare\)

Find a root of \(f(x)=x^3-4x-9=0\) in \([2,3]\) using 3 iterations of bisection.

Solution

PYQ 2023 — Lagrange Interpolation

Given \((0,1),(1,3),(2,7),(3,13)\), find \(f(1.5)\) using Lagrange interpolation.

Solution

These points lie on \(f(x)=x^2+x+1\). Let's verify: \(0+0+1=1\checkmark,1+1+1=3\checkmark,4+2+1=7\checkmark,9+3+1=13\checkmark\). Lagrange with 4 points (or just use formula): \(f(1.5)=(1.5)^2+1.5+1=2.25+1.5+1=4.75\). Lagrange formula: \(L_0=\dfrac{(1.5-1)(1.5-2)(1.5-3)}{(0-1)(0-2)(0-3)}=\dfrac{(0.5)(-0.5)(-1.5)}{(-6)}=\dfrac{0.375}{6}... \). Direct use of polynomial gives \(4.75\). \(\blacksquare\)

PYQ 2021 — Newton's Forward Difference

Using the following table, find \(f(1.5)\): \(x: 1,2,3,4\); \(y: 1,8,27,64\) (i.e., \(y=x^3\)).

Solution

Forward differences: \(\Delta y: 7,19,37\). \(\Delta^2y: 12,18\). \(\Delta^3y: 6\). \(\Delta^4y=0\). Here \(x_0=1,h=1,s=(1.5-1)/1=0.5\). Newton's forward: \(f(1.5)=1+0.5\times7+\dfrac{0.5(-0.5)}{2}\times12+\dfrac{0.5(-0.5)(-1.5)}{6}\times6=1+3.5-1.5+0.375=3.375\). And \(1.5^3=3.375\). \(\checkmark\) \(\blacksquare\)

PYQ 2023 — RK4 Method

Solve \(y'=x+y,y(0)=1\) using RK4 with \(h=0.1\). Find \(y(0.1)\).

Solution

\(f(x,y)=x+y\). At \(x_0=0,y_0=1\): \(k_1=f(0,1)=1\). \(k_2=f(0.05,1+0.05)=f(0.05,1.05)=0.05+1.05=1.1\). \(k_3=f(0.05,1+0.05\times1.1)=f(0.05,1.055)=1.105\). \(k_4=f(0.1,1+0.1\times1.105)=f(0.1,1.1105)=1.2105\). \(y_1=1+\dfrac{0.1}{6}(1+2(1.1)+2(1.105)+1.2105)=1+\dfrac{0.1}{6}(6.6205)=1+0.11034=1.11034\). Exact: \(y=2e^x-x-1\Rightarrow y(0.1)=2e^{0.1}-1.1=2(1.10517)-1.1=1.11034\). \(\checkmark\) \(\blacksquare\)

PYQ 2021 — Euler's Method

Use Euler's method to solve \(y'=x+y,y(0)=1\) with \(h=0.2\). Find \(y(0.4)\).

Solution

\(y_{n+1}=y_n+hf(x_n,y_n)\). \(y(0.2)=1+0.2(0+1)=1.2\). \(y(0.4)=1.2+0.2(0.2+1.2)=1.2+0.28=1.48\). (Exact: \(2e^{0.4}-1.4=2(1.4918)-1.4=1.5836\); Euler has significant error due to large \(h\).) \(\blacksquare\)

PYQ 2019 — Modified Euler (Heun's Method)

Solve \(y'=x+y^2,y(0)=1\) using Heun's method with \(h=0.1\). Compute \(y(0.1)\).

Solution

Predictor: \(y^*=y_0+hf(x_0,y_0)=1+0.1(0+1)=1.1\). Corrector: \(y_1=y_0+\dfrac{h}{2}[f(x_0,y_0)+f(x_1,y^*)]=1+\dfrac{0.1}{2}[f(0,1)+f(0.1,1.1)]=1+0.05[(0+1)+(0.1+1.21)]=1+0.05[1+1.31]=1+0.05(2.31)=1+0.1155=1.1155\). \(\blacksquare\)

PYQ 2018 — Regula Falsi (False Position)

Find a root of \(f(x)=x^3-2x-5=0\) in \([2,3]\) using Regula Falsi. Do 2 iterations.

Solution

\(f(2)=-1,f(3)=16\). Iter 1: \(x_1=\frac{2\cdot16-3\cdot(-1)}{16-(-1)}=\frac{32+3}{17}=\frac{35}{17}\approx2.0588\). \(f(2.0588)=(2.0588)^3-2(2.0588)-5\approx8.728-4.118-5=-0.390\). Root in \([2.0588,3]\). Iter 2: \(x_2=\frac{2.0588\times16-3\times(-0.390)}{16+0.390}=\frac{32.94+1.17}{16.39}\approx2.080\). Converging to \(\approx2.0946\). \(\blacksquare\)

PYQ 2017 — Fixed Point Iteration

Solve \(x=e^{-x}\) by fixed point iteration starting with \(x_0=0.5\). Show convergence condition.

Solution

Iteration: \(x_{n+1}=e^{-x_n}\). Convergence: \(|g'(x)|=|-e^{-x}|=e^{-x}<1\) for \(x>0\). At root \(x^*\approx0.5671\): \(|g'(x^*)|=e^{-0.5671}\approx0.567<1\). \(\checkmark\) Iter: \(x_1=e^{-0.5}=0.6065,x_2=e^{-0.6065}=0.5454,x_3=0.5796,x_4=0.5604,\ldots\to0.5671\). \(\blacksquare\)

PYQ 2016 — Secant Method

Use the secant method to find a root of \(f(x)=x^2-5\) starting with \(x_0=2,x_1=3\).

Solution

\(x_{n+1}=x_n-f(x_n)\dfrac{x_n-x_{n-1}}{f(x_n)-f(x_{n-1})}\). \(f(2)=-1,f(3)=4\). \(x_2=3-4\cdot\dfrac{3-2}{4-(-1)}=3-\dfrac{4}{5}=2.2\). \(f(2.2)=4.84-5=-0.16\). \(x_3=2.2-(-0.16)\dfrac{2.2-3}{-0.16-4}=2.2-(-0.16)\dfrac{-0.8}{-4.16}=2.2-0.031\approx2.236\). Converges to \(\sqrt5\approx2.2361\). \(\blacksquare\)

PYQ 2015 — Rate of Convergence

Compare the order of convergence of bisection, Newton-Raphson, and secant methods.

Solution

Bisection: linear convergence, order 1, rate 1/2. Error halves each iteration. Newton-Raphson: quadratic convergence, order 2. \(e_{n+1}\approx Ce_n^2\). Secant: superlinear, order \(\phi=(1+\sqrt5)/2\approx1.618\) (golden ratio). \(e_{n+1}\approx Ce_n^\phi\). In practice (per iteration cost): NR requires \(f'\); secant uses two function evaluations. NR most efficient per iteration; bisection always converges but slowly. \(\blacksquare\)

PYQ 2014 — Muller's Method (Concept)

Describe Muller's method for finding complex roots of a polynomial.

Solution

Muller's method fits a quadratic through three points \((x_{n-2},f_{n-2}),(x_{n-1},f_{n-1}),(x_n,f_n)\) and finds its roots using the quadratic formula. Formula: \(x_{n+1}=x_n-\dfrac{2f_n}{w\pm\sqrt{w^2-4f_n\cdot\delta}}\) where \(w=\delta+\gamma,\delta=f[x_{n-1},x_n],\gamma=f[x_{n-2},x_{n-1},x_n](x_n-x_{n-1})\). Order of convergence \(\approx1.84\). Advantage: finds complex and real roots, including repeated roots. \(\blacksquare\)

PYQ 2017 — Divided Differences

Given \((0,1),(1,4),(3,40),(4,85)\), find Newton's divided difference interpolating polynomial.

Solution

Divided diff table: \(f[0]=1,f[1]=4,f[3]=40,f[4]=85\). \(f[0,1]=(4-1)/1=3\). \(f[1,3]=(40-4)/2=18\). \(f[3,4]=(85-40)/1=45\). \(f[0,1,3]=(18-3)/3=5\). \(f[1,3,4]=(45-18)/3=9\). \(f[0,1,3,4]=(9-5)/4=1\). Polynomial: \(P(x)=1+3x+5x(x-1)+1\cdot x(x-1)(x-3)=1+3x+5x^2-5x+x^3-4x^2+3x=x^3+x^2+x+1\). \(\blacksquare\)

PYQ 2016 — Hermite Interpolation

Define Hermite interpolation and state its error formula.

Solution

Hermite interpolation: fits a polynomial matching both function values \(f(x_i)\) and derivative values \(f'(x_i)\) at nodes. For \(n+1\) nodes: degree \(\le2n+1\) polynomial. Using divided differences with repeated nodes: if \(x_0=x_1=a\): \(f[a,a]=f'(a)\). Error: \(E(x)=\dfrac{f^{(2n+2)}(\xi)}{(2n+2)!}\prod_{i=0}^n(x-x_i)^2\) for some \(\xi\). More accurate than Lagrange since derivative info reduces oscillation. \(\blacksquare\)

PYQ 2015 — Cubic Spline

Explain cubic spline interpolation and state its advantages over polynomial interpolation.

Solution

Cubic spline: piecewise cubic polynomials \(S_i(x)\) on each \([x_i,x_{i+1}]\) satisfying: (1) \(S_i(x_i)=y_i,S_i(x_{i+1})=y_{i+1}\); (2) \(S_{i-1}(x_i)=S_i(x_i)\) (C0 continuity); (3) \(S'_{i-1}=S'_i\) at interior nodes (C1); (4) \(S''_{i-1}=S''_i\) (C2). Natural spline: \(S''(x_0)=S''(x_n)=0\). Advantages over high-degree polynomial: no Runge phenomenon, smooth, local changes only affect nearby intervals. \(\blacksquare\)

PYQ 2013 — Newton's Backward Difference Formula

Given \(y(25)=0.4226,y(30)=0.5,y(35)=0.5736,y(40)=0.6428\), find \(y(38)\) using Newton's backward difference formula.

Solution

\(h=5,x_n=40,s=(38-40)/5=-0.4\). Backward differences: \(\nabla y_{40}=0.6428-0.5736=0.0692\). \(\nabla^2=0.5736-0.5+0.5-0.4226... \) \(\nabla y_{35}=0.5736-0.5=0.0736,\nabla y_{30}=0.5-0.4226=0.0774\). \(\nabla^2y_{40}=0.0692-0.0736=-0.0044\). \(\nabla^2y_{35}=0.0736-0.0774=-0.0038\). \(\nabla^3y_{40}=-0.0044-(-0.0038)=-0.0006\). \(y(38)=0.6428+(-0.4)(0.0692)+\frac{(-0.4)(-0.4+1)}{2!}(-0.0044)+\cdots=0.6428-0.02768+0.000528\approx0.6157\). \(\blacksquare\)

PYQ 2012 — Inverse Interpolation

Given a table of \((x,y)\) values, find \(x\) for \(y=0.5\). Explain the method.

Solution

Inverse interpolation: swap roles of \(x\) and \(y\). Apply Newton's or Lagrange's formula treating \(y\) as independent variable and \(x\) as function. Alternatively: if interpolating polynomial \(P(x)=0.5\), solve numerically (Newton-Raphson on \(P(x)-0.5=0\)). For equally spaced \(y\) values: use Newton's forward difference formula with \(y_0=0.5\) to find corresponding \(x\) directly. \(\blacksquare\)

PYQ 2011 — Error in Interpolation

Find the maximum error in linear interpolation of \(f(x)=\sin x\) on \([0,\pi/2]\) with equally-spaced nodes of spacing \(h\).

Solution

Error in linear interpolation: \(|E(x)|\le\dfrac{h^2}{8}\max|f''(\xi)|\) for \(\xi\in[a,b]\). \(f''(x)=-\sin x\Rightarrow|f''|\le1\). Max error \(\le h^2/8\). For \(n\) equally spaced points on \([0,\pi/2]\): \(h=\pi/(2n)\), max error \(\le\dfrac{\pi^2}{32n^2}\). For error \(<0.001\): \(n>\pi/(4\sqrt{0.008})\approx27.8\Rightarrow n=28\). \(\blacksquare\)

PYQ 2017 — Romberg Integration

Describe Romberg integration and explain how it achieves higher accuracy.

Solution

Romberg: systematic use of Richardson extrapolation on trapezoidal rule. Let \(T(h)\) = trapezoidal with step \(h\). Error: \(T(h)=I+c_1h^2+c_2h^4+\cdots\). Richardson: \(R_{n,1}=T(h/2^n)\), \(R_{n,m}=\dfrac{4^{m-1}R_{n,m-1}-R_{n-1,m-1}}{4^{m-1}-1}\). Each column eliminates one error term: \(R_{\cdot,2}\) eliminates \(h^2\) error (like Simpson's); \(R_{\cdot,3}\) eliminates \(h^4\); etc. Converges to \(I\) with very high order. \(\blacksquare\)

PYQ 2016 — Gaussian Quadrature (n=2)

Evaluate \(\int_{-1}^1(x^4+1)\,dx\) using 2-point Gauss-Legendre quadrature. Verify with exact.

Solution

2-point GL: \(\int_{-1}^1f(x)\,dx\approx f(-1/\sqrt3)+f(1/\sqrt3)\). Nodes: \(\pm1/\sqrt3\). \(f(1/\sqrt3)=(1/3)^2+1=1/9+1=10/9\). \(f(-1/\sqrt3)=10/9\). Approximation: \(10/9+10/9=20/9\approx2.222\). Exact: \([x^5/5+x]_{-1}^1=2/5+2=12/5=2.4\). Error: \(0.178\). (2-point GL exact for polynomials of degree \(\le3\); here degree 4 — need 3-point GL for exactness.) \(\blacksquare\)

PYQ 2015 — Error in Simpson's Rule

Show that the error in Simpson's 1/3 rule over \([a,b]\) with 2 panels is \(-\dfrac{h^5}{90}f^{(4)}(\xi)\).

Solution

Simpson approximates \(\int_{x_0}^{x_2}f\,dx\). Expand \(f\) in Taylor around \(x_1\): \(f(x_1+t)=f_1+tf_1'+\frac{t^2}{2}f_1''+\frac{t^3}{6}f_1'''+\frac{t^4}{24}f_1^{(4)}+\cdots\). PYQ 2004 — Truncation vs Rounding Error

Distinguish between truncation error and round-off error in numerical computation.

Solution

Truncation error: error from approximating mathematical operations (e.g., replacing infinite Taylor series by finite terms, replacing derivatives by finite differences). Reduces with smaller step \(h\). Round-off error: error from representing real numbers in finite precision (floating point). Grows as \(h\to0\) (catastrophic cancellation). Trade-off: optimal \(h\) balances both. For numerical differentiation: truncation \(\sim h\), round-off \(\sim\epsilon_M/h\); optimal \(h\sim\sqrt{\epsilon_M}\approx10^{-8}\) for double precision. \(\blacksquare\)

PYQ 2002 — Chebyshev Nodes

What are Chebyshev nodes? Why are they preferred over equally-spaced nodes?

Solution

Chebyshev nodes on \([-1,1]\): \(x_k=\cos\!\left(\frac{2k+1}{2n+2}\pi\right),k=0,\ldots,n\). Clustered at endpoints. Minimize the maximum of \(|\prod(x-x_k)|\) over \([-1,1]\): \(\max|\omega(x)|=\frac{1}{2^n}\) (minimal). Equally-spaced: \(\max|\omega|\) grows exponentially with \(n\) → Runge phenomenon. Chebyshev nodes: near-minimax interpolation error, no Runge phenomenon. Use: FFT, spectral methods, near-best polynomial approximation. \(\blacksquare\)

PYQ 2001 — Gaussian Elimination with Partial Pivoting

Why is partial pivoting important in Gaussian elimination? Illustrate with an example.

Solution

Without pivoting, small pivot causes division by small number → large round-off errors. Partial pivoting: at each step, swap rows to bring largest element in current column to pivot position. Example: \(\begin{pmatrix}0.001&1\\1&1\end{pmatrix}\begin{pmatrix}x\\y\end{pmatrix}=\begin{pmatrix}1\\2\end{pmatrix}\). Without pivoting: \(x=(1000-2)/(-999)\approx-0.998\), large error. With pivoting: swap rows, eliminate cleanly. Result: \(x=y=1\) (exact for this system). Growth factor bounded to \(2^{n-1}\) with partial pivoting. \(\blacksquare\)

PYQ 2023 — Jacobi vs Gauss-Seidel Convergence

Compare the convergence rates of Jacobi and Gauss-Seidel iteration for solving \(Ax=b\). Under what conditions does each converge?

Solution

Jacobi: \(x_i^{(k+1)} = \frac{1}{a_{ii}}\!\left(b_i - \sum_{j\neq i}a_{ij}x_j^{(k)}\right)\). Uses only old values. Iteration matrix \(B_J = -D^{-1}(L+U)\). Convergence iff \(\rho(B_J)<1\). Gauss-Seidel: uses updated values immediately. Iteration matrix \(B_{GS}=-(D+L)^{-1}U\). For many classes of matrices \(\rho(B_{GS})=[\rho(B_J)]^2\) (Stein-Rosenberg theorem), so GS converges about twice as fast per iteration. Both converge for strictly diagonally dominant or symmetric positive definite \(A\). GS converges whenever Jacobi does (for SPD and irreducibly diagonally dominant matrices). Counter-example: some matrices where Jacobi converges but GS diverges exist, but they are non-SPD. In practice, GS is preferred for speed. \(\blacksquare\)

PYQ 2014 — Partial vs Complete Pivoting

Distinguish between partial and complete pivoting in Gaussian elimination. Analyse their effect on numerical stability.

Solution

Partial pivoting: at step \(k\), swap rows to bring the largest element in column \(k\) (below diagonal) to pivot position. Cost: \(O(n)\) comparisons per step. Complete pivoting: swap both rows and columns to bring the largest element in the remaining submatrix to pivot. Cost: \(O(n^2)\) comparisons per step. Stability: partial pivoting: growth factor \(g\le 2^{n-1}\) (theoretically), but in practice rarely large; standard and sufficient. Complete pivoting: growth factor \(g\le(n\prod_{k=1}^n k^{1/(k-1)})^{1/2}\), empirically much smaller. Complete pivoting is more stable but expensive; partial pivoting is the standard practice. LU with partial pivoting is backward stable: computed solution \(\hat{\mathbf{x}}\) satisfies \((A+\delta A)\hat{\mathbf{x}}=\mathbf{b}\) with \(\|\delta A\|\le C u\|A\|\) where \(u\) = machine epsilon. \(\blacksquare\)

PYQ 2013 — Thomas Algorithm for Tridiagonal Systems

Describe the Thomas algorithm (tridiagonal matrix algorithm) for solving a tridiagonal system \(a_i x_{i-1}+b_i x_i+c_i x_{i+1}=d_i\). State its complexity.

Solution

Back substitution: \(x_n=d'_n/w_n\); for \(i=n-1,\ldots,1\): \(x_i=(d'_i-c_i x_{i+1})/w_i\). Complexity: \(O(n)\) operations (only \(5n-4\) multiplications/additions). Numerically stable without pivoting if the matrix is diagonally dominant or SPD. Applications: cubic spline interpolation, Crank-Nicolson for PDEs. \(\blacksquare\)

Solution

CG minimizes \(\phi(\mathbf{x})=\frac12\mathbf{x}^TA\mathbf{x}-\mathbf{b}^T\mathbf{x}\) over Krylov subspace \(\mathcal{K}_k=\text{span}\{\mathbf{r}_0,A\mathbf{r}_0,\ldots,A^{k-1}\mathbf{r}_0\}\). Algorithm: \(\mathbf{r}_0=\mathbf{b}-A\mathbf{x}_0\), \(\mathbf{p}_0=\mathbf{r}_0\). At each step: \(\alpha_k=\mathbf{r}_k^T\mathbf{r}_k/\mathbf{p}_k^TA\mathbf{p}_k\), \(\mathbf{x}_{k+1}=\mathbf{x}_k+\alpha_k\mathbf{p}_k\), \(\mathbf{r}_{k+1}=\mathbf{r}_k-\alpha_k A\mathbf{p}_k\), \(\beta_k=\mathbf{r}_{k+1}^T\mathbf{r}_{k+1}/\mathbf{r}_k^T\mathbf{r}_k\), \(\mathbf{p}_{k+1}=\mathbf{r}_{k+1}+\beta_k\mathbf{p}_k\). Convergence: \(\|\mathbf{e}_k\|_A\le2\left(\frac{\sqrt\kappa-1}{\sqrt\kappa+1}\right)^k\|\mathbf{e}_0\|_A\). Terminates in at most \(n\) steps exactly (finite precision). Effective with preconditioning. \(\blacksquare\)

PYQ 2011 — Stability and Convergence of Finite Difference Schemes

Solution

PYQ 2006 — Tau Method for ODEs

Describe Lanczos's tau method for solving the BVP \(y''+y=x\), \(y(0)=y(1)=0\). How does it differ from the Galerkin method?

Solution

Tau method: seek approximate solution \(y_n(x)=\sum_{k=0}^n a_k T_k(x)\) (Chebyshev expansion) satisfying the ODE approximately. Instead of requiring the residual to be orthogonal to all basis functions (Galerkin), the tau method: (1) expands all functions in Chebyshev series; (2) the differential equation gives a relation between expansion coefficients; (3) boundary conditions replace the last 2 equations (for second-order ODE). The residual is of the form \(R_n(x)=\tau_1 T_{n+1}(x)+\tau_2 T_{n+2}(x)\) (tail terms). Key advantage over Galerkin: exact boundary condition enforcement while maintaining spectral accuracy. Produces banded algebraic systems for polynomial bases. Exponential convergence for smooth \(f\). \(\blacksquare\)

PYQ 2005 — Collocation Methods for ODEs

Describe the collocation method for ODEs. For the BVP \(y''=f(x,y)\), \(y(a)=y(b)=0\), how are the collocation points chosen to achieve high accuracy?

Solution

Collocation: seek \(y_n\in P_n\) (polynomial of degree \(n\)) such that \(y_n''(x_i)=f(x_i,y_n(x_i))\) at \(n-1\) interior collocation points \(x_1,\ldots,x_{n-1}\), plus two boundary conditions. This gives \(n+1\) equations for \(n+1\) coefficients. Choice of collocation points: (1) Equally spaced: only \(O(h^n)\) accuracy. (2) Gauss-Legendre points (roots of \(P_n\)): superconvergence — order \(2n\). (3) Gauss-Lobatto points (include endpoints): order \(2n-2\), useful for BVPs. Chebyshev collocation: near-minimax approximation, avoids Runge phenomenon. Spectral collocation on \(N\) Chebyshev nodes: exponential convergence for smooth solutions. \(\blacksquare\)

PYQ 2006 — Catastrophic Cancellation

Solution

Catastrophic cancellation: when two nearly equal floating-point numbers are subtracted, significant digits are lost. Result has few correct digits even if operands are accurately represented. Example: \(x=1.23456789012345\), \(y=1.23456789012344\). True difference: \(10^{-14}\). PYQ 2005 — Numerical Stability: Backward Stability and Forward Error

Define forward error, backward error, and backward stability for a numerical algorithm. Illustrate with the example of computing the inner product \(\mathbf{x}^T\mathbf{y}\).

Solution

Forward error: \(\|\hat{f}(x)-f(x)\|\) — how far the computed answer \(\hat{f}(x)\) is from the true answer \(f(x)\). Backward error: smallest \(\|\delta x\|\) such that \(\hat{f}(x)=f(x+\delta x)\) — how much we must perturb the input to make our computed answer exactly right. Backward stability: algorithm is backward stable if \(\|\delta x\|/\|x\|=O(u)\) (machine epsilon) for all \(x\). Backward stable \(\Rightarrow\) forward error \(\le\kappa(f)\cdot O(u)\). Inner product \(\hat{s}=\sum_{i=1}^n\hat{x}_iy_i\): floating-point evaluation satisfies \(\hat{s}=\mathbf{x}^T\mathbf{y}+O(nu\|\mathbf{x}\|\|\mathbf{y}\|)\). Relative error \(\le nu\), so backward stable for small \(n\). For large \(n\): pairwise summation or compensated summation (Kahan) reduces error to \(O(u)\) regardless of \(n\). \(\blacksquare\)

Trapezoidal rule: \(\int_a^b f\,dx\approx\dfrac{h}{2}[f(x_0)+2f(x_1)+\cdots+2f(x_{n-1})+f(x_n)]\). Error bound: \(|E_T|\le\dfrac{(b-a)h^2}{12}\max|f''|\).

Points \(x=0,0.25,0.5,0.75,1\). Values: \(f(0)=1,\;f(0.25)\approx0.9394,\;f(0.5)\approx0.7788,\;f(0.75)\approx0.5698,\;f(1)\approx0.3679\).

Trapezoidal: \(\frac{0.25}{2}[1+2(0.9394+0.7788+0.5698)+0.3679]=\frac{0.25}{2}[1+4.5760+0.3679]=\frac{0.25}{2}(5.9439)\approx0.7430\).

For Simpson's 1/3 (same 5 pts): \(\frac{0.25}{3}[1+4(0.9394)+2(0.7788)+4(0.5698)+0.3679]=\frac{0.25}{3}(8.9613)\approx0.7468\).

Exact \(\approx0.7468\). Trapezoidal error \(\approx0.0038\); Simpson error \(\approx0\) (4th-order). Error bound for trapezoidal: \(|f''(x)|=|2e^{-x^2}(2x^2-1)|\le2\), so \(|E_T|\le\frac{(1)(0.25)^2}{12}(2)\approx0.0104\). \(\blacksquare\)

PYQ 2026 Q5b (10m) — Newton-Raphson: Quadratic Convergence & Application

Describe Newton-Raphson method. Prove that it has quadratic convergence near a simple root. Apply it to find \(\sqrt[3]{28}\) correct to 4 decimal places.

Solution

NR formula: \(x_{n+1}=x_n-\dfrac{f(x_n)}{f'(x_n)}\). Quadratic convergence: error \(e_{n+1}\approx\dfrac{f''(\xi)}{2f'(\xi)}e_n^2\) (see proof in §Proofs above).

For \(\sqrt[3]{28}\): \(f(x)=x^3-28\), \(f'(x)=3x^2\). Formula: \(x_{n+1}=x_n-\dfrac{x_n^3-28}{3x_n^2}=\dfrac{2x_n^3+28}{3x_n^2}\).

Start \(x_0=3\): \(x_1=\dfrac{2(27)+28}{3(9)}=\dfrac{82}{27}\approx3.0370\).

\(x_2=\dfrac{2(3.0370)^3+28}{3(3.0370)^2}=\dfrac{2(28.04)+28}{27.67}=\dfrac{84.08}{27.67}\approx3.0366\).

\(x_3\approx3.0366\) (converged). \(\sqrt[3]{28}\approx3.0366\). \(\blacksquare\)

PYQ 2026 Q5c (10m) — Logic Gates & NAND Universality

What are logic gates? Define AND, OR, NOT, NAND, NOR, XOR. Draw truth tables for NAND and XOR. Show NAND is universal.

Solution

Logic gates implement Boolean operations on binary inputs.

NAND truth table: \(00\to1,\;01\to1,\;10\to1,\;11\to0\). XOR truth table: \(00\to0,\;01\to1,\;10\to1,\;11\to0\).

NAND is universal (any Boolean function buildable from NAND alone):
• NOT: \(\overline{A}=A\text{ NAND }A\)
• AND: \(A\cdot B=(A\text{ NAND }B)\text{ NAND }(A\text{ NAND }B)\)
• OR: \(A+B=(A\text{ NAND }A)\text{ NAND }(B\text{ NAND }B)\)

Since AND, OR, NOT form a functionally complete set, and all three are realizable with NAND, NAND alone suffices for any Boolean function. \(\blacksquare\)

Represent \(-37\) in 8-bit signed magnitude, one's complement, and two's complement. Also represent \(1.5\) in IEEE 754 single-precision format.

PYQ 2026 Q6b-ii (7m) — Hex to Binary/Decimal; Repeating Binary Fraction

Convert \((2A3F)_{16}\) to binary and decimal. Convert \((0.1)_{10}\) to binary (show it is a repeating fraction).

\(2=0010,\;A=1010,\;3=0011,\;F=1111\). So \((2A3F)_{16}=(0010\,1010\,0011\,1111)_2\).

Decimal: \(2\times16^3+10\times16^2+3\times16+15=8192+2560+48+15=10815\).

PYQ 2026 Q8b (15m) — Runge-Kutta 4th Order Method

Derive the RK4 method. Apply it with \(h=0.1\) to solve \(y'=x+y\), \(y(0)=1\), for \(y(0.1)\).

Solution

RK4 (weights from Simpson's 1/3 on slope estimates at \(x_n,\,x_n+h/2,\,x_n+h/2,\,x_n+h\)): \[k_1=hf(x_n,y_n),\quad k_2=hf\!\left(x_n+\tfrac{h}{2},y_n+\tfrac{k_1}{2}\right),\] \[k_3=hf\!\left(x_n+\tfrac{h}{2},y_n+\tfrac{k_2}{2}\right),\quad k_4=hf(x_n+h,y_n+k_3),\] \[y_{n+1}=y_n+\tfrac{1}{6}(k_1+2k_2+2k_3+k_4).\] Local truncation error \(O(h^5)\), global error \(O(h^4)\).

At \(x_0=0,y_0=1\), \(f(x,y)=x+y\):

\(k_1=0.1(0+1)=0.1\).

\(k_2=0.1(0.05+1+0.05)=0.1(1.1)=0.11\).

\(k_3=0.1(0.05+1+0.055)=0.1(1.105)=0.1105\).

\(k_4=0.1(0.1+1+0.1105)=0.1(1.2105)=0.12105\).

\(y(0.1)=1+\tfrac{1}{6}(0.1+0.22+0.221+0.12105)=1+\tfrac{0.66205}{6}=1+0.11034=1.11034\).

Exact: \(y=2e^x-x-1\Rightarrow y(0.1)=2e^{0.1}-1.1\approx1.11034\). \(\checkmark\) \(\blacksquare\)
