§ Proofs — Root Finding

Newton-Raphson: Quadratic Convergence — Proof

If \(f(r)=0\), \(f'(r)\ne0\), and \(f''\) is bounded near \(r\), then NR iteration \(x_{n+1}=x_n-\dfrac{f(x_n)}{f'(x_n)}\) converges quadratically: \(e_{n+1}\approx\dfrac{f''(r)}{2f'(r)}e_n^2\) where \(e_n=x_n-r\).

Proof

Step 1 Taylor expand \(f\) around \(r\): \(f(x_n)=f(r)+e_nf'(r)+\dfrac{e_n^2}{2}f''(\xi)\) for some \(\xi\) between \(r\) and \(x_n\). Since \(f(r)=0\): \(f(x_n)=e_nf'(r)+\dfrac{e_n^2}{2}f''(\xi)\).

Step 2 Similarly: \(f'(x_n)=f'(r)+e_nf''(\eta)\) for some \(\eta\).

Step 3 \(e_{n+1}=x_{n+1}-r=x_n-\dfrac{f(x_n)}{f'(x_n)}-r=e_n-\dfrac{e_nf'(r)+e_n^2f''(\xi)/2}{f'(r)+e_nf''(\eta)}=\dfrac{e_n^2f''(\xi)/2}{f'(r)+e_nf''(\eta)}\approx\dfrac{f''(r)}{2f'(r)}e_n^2\) (for small \(e_n\)). \(\blacksquare\)

Bisection Method: Convergence — Proof

If \(f\) is continuous on \([a,b]\) and \(f(a)f(b)<0\), bisection converges with \(|e_n|\le\dfrac{b-a}{2^n}\).

Proof

After \(n\) steps, the interval containing the root has length \((b-a)/2^n\). The midpoint \(x_n\) satisfies \(|x_n-r|\le(b-a)/2^{n+1}\). As \(n\to\infty\), \(|e_n|\to0\) (linear convergence with rate 1/2). \(\blacksquare\)

§ Proofs — Interpolation

Newton's Forward Difference Formula — Derivation

\(y(x)=y_0+s\Delta y_0+\dfrac{s(s-1)}{2!}\Delta^2y_0+\dfrac{s(s-1)(s-2)}{3!}\Delta^3y_0+\cdots\) where \(s=(x-x_0)/h\).

Derivation

Use the shift operator \(E=1+\Delta\). At \(x=x_0+sh\): \(y(x)=E^sy_0=(1+\Delta)^sy_0\). Expand binomially: \(y=\left(1+s\Delta+\binom{s}{2}\Delta^2+\binom{s}{3}\Delta^3+\cdots\right)y_0=y_0+s\Delta y_0+\dfrac{s(s-1)}{2!}\Delta^2y_0+\cdots\). \(\blacksquare\)

Lagrange Interpolation Error — Proof

Error in Lagrange interpolation through \((n+1)\) points: \(E(x)=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}\prod_{i=0}^n(x-x_i)\) for some \(\xi\) in the interval.

Proof

Let \(\omega(x)=\prod_{i=0}^n(x-x_i)\). Define \(g(t)=f(t)-P_n(t)-\lambda\omega(t)\) where \(\lambda\) is chosen so that \(g(x)=0\). Then \(g\) has \((n+2)\) zeros: \(x_0,x_1,\ldots,x_n,x\). By Rolle's theorem applied \((n+1)\) times: \(g^{(n+1)}(\xi)=0\) for some \(\xi\). So \(f^{(n+1)}(\xi)-(n+1)!\lambda=0\Rightarrow\lambda=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}\). Since \(g(x)=f(x)-P_n(x)-\lambda\omega(x)=0\): \(f(x)-P_n(x)=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}\omega(x)\). \(\blacksquare\)

§ Proofs — Numerical Integration

Simpson's 1/3 Rule — Derivation

\(\int_a^b f(x)\,dx\approx\dfrac{h}{3}[f(x_0)+4f(x_1)+f(x_2)]\) where \(h=(b-a)/2\). Error: \(-\dfrac{h^5}{90}f^{(4)}(\xi)\).

Derivation

Step 1 Fit quadratic through \((x_0,f_0),(x_1,f_1),(x_2,f_2)\) with \(x_0=a,x_1=(a+b)/2,x_2=b\): \(P_2(x)=\dfrac{(x-x_1)(x-x_2)}{(x_0-x_1)(x_0-x_2)}f_0+\dfrac{(x-x_0)(x-x_2)}{(x_1-x_0)(x_1-x_2)}f_1+\dfrac{(x-x_0)(x-x_1)}{(x_2-x_0)(x_2-x_1)}f_2\).

Step 2 Integrate: with \(s=(x-x_1)/h\), \(\int_{-1}^1(s^2-s^2)ds... \) Using \(\int_{x_0}^{x_2}P_2\,dx=h\!\int_{-1}^1\!\left[\dfrac{s(s-1)}{2}f_0-\dfrac{s^2-1}{1}f_1+\dfrac{s(s+1)}{2}f_2\right]ds\). \(\int_{-1}^1s(s-1)ds=2/3-0\)... Computing each coefficient: \(f_0:\int_{-1}^1\frac{s(s-1)}{2}ds=\frac{1}{2}\cdot\frac{2}{3}=\frac{1}{3}\). \(f_1:\int_{-1}^1(1-s^2)ds=\frac{4}{3}\). \(f_2:\int_{-1}^1\frac{s(s+1)}{2}ds=\frac{1}{3}\). Total: \(h(f_0/3+4f_1/3+f_2/3)=\frac{h}{3}(f_0+4f_1+f_2)\). \(\blacksquare\)

Composite Rules & Error Summary
  • Trapezoidal (composite, \(n\) subintervals): \(\dfrac{h}{2}[y_0+2(y_1+\cdots+y_{n-1})+y_n]\), error \(O(h^2)\)
  • Simpson's 1/3 (composite, \(n\) even): \(\dfrac{h}{3}[y_0+4y_1+2y_2+4y_3+\cdots+4y_{n-1}+y_n]\), error \(O(h^4)\)
  • Simpson's 3/8 (multiple of 3 subintervals): \(\dfrac{3h}{8}[y_0+3y_1+3y_2+2y_3+3y_4+\cdots+y_n]\)

§ Proofs — Numerical ODEs

RK4 Algorithm — Derivation Idea

For \(y'=f(x,y),y(x_0)=y_0\). RK4 step: \(y_{n+1}=y_n+\dfrac{h}{6}(k_1+2k_2+2k_3+k_4)\) where \(k_1=f(x_n,y_n),k_2=f(x_n+h/2,y_n+hk_1/2),k_3=f(x_n+h/2,y_n+hk_2/2),k_4=f(x_n+h,y_n+hk_3)\).

Derivation (Taylor expansion matching)

The exact solution satisfies \(y(x_{n+1})=y(x_n)+hy'(x_n)+\dfrac{h^2}{2}y''(x_n)+\dfrac{h^3}{6}y'''(x_n)+\dfrac{h^4}{24}y^{(4)}(x_n)+O(h^5)\). The RK4 coefficients are chosen so that the weighted combination \(\frac{h}{6}(k_1+2k_2+2k_3+k_4)\) matches these Taylor terms up to \(O(h^4)\). The weights \(1,2,2,1\) (from Simpson's 1/3 rule applied to slope evaluation) ensure 4th-order accuracy. Local truncation error: \(O(h^5)\), global error: \(O(h^4)\). \(\blacksquare\)

§ PYQ — Root Finding (2000–2024)

PYQ 2024 — Newton-Raphson Iteration

Find \(\sqrt{3}\) using Newton-Raphson starting from \(x_0=2\). Perform 2 iterations.

Solution

Set \(f(x)=x^2-3\). \(f'(x)=2x\). NR: \(x_{n+1}=x_n-\dfrac{x_n^2-3}{2x_n}=\dfrac{x_n^2+3}{2x_n}\).

Iter 1: \(x_1=\dfrac{4+3}{4}=\dfrac{7}{4}=1.75\).

Iter 2: \(x_2=\dfrac{(7/4)^2+3}{2\cdot7/4}=\dfrac{49/16+48/16}{7/2}=\dfrac{97/16}{7/2}=\dfrac{97}{56}\approx1.73214\). True value: \(\sqrt{3}\approx1.73205\). Error \(\approx0.00009\). \(\blacksquare\)

PYQ 2022 — N-R for Transcendental Equation

Find the root of \(xe^x=1\) near \(x_0=0.5\) using 2 iterations of Newton-Raphson.

Solution

\(f(x)=xe^x-1,f'(x)=e^x+xe^x=(1+x)e^x\). \(x_1=0.5-\dfrac{0.5e^{0.5}-1}{1.5e^{0.5}}=0.5-\dfrac{0.5\times1.6487-1}{1.5\times1.6487}=0.5-\dfrac{0.8244-1}{2.4731}=0.5-\dfrac{-0.1756}{2.4731}=0.5+0.0710=0.5710\). \(x_2\approx0.5671\) (converges to \(0.5671\)). \(\blacksquare\)

PYQ 2020 — Bisection Method

Find a root of \(f(x)=x^3-4x-9=0\) in \([2,3]\) using 3 iterations of bisection.

Solution

\(f(2)=8-8-9=-9<0\), \(f(3)=27-12-9=6>0\). Root in \([2,3]\). Iter 1: \(x_1=2.5,f(2.5)=15.625-10-9=-3.375<0\). Root in \([2.5,3]\). Iter 2: \(x_2=2.75,f(2.75)=20.797-11-9=0.797>0\). Root in \([2.5,2.75]\). Iter 3: \(x_3=2.625,f(2.625)\approx18.07-10.5-9=-1.43<0\). Root in \([2.625,2.75]\). Approximate root \(\approx2.6875\). \(\blacksquare\)

§ PYQ — Interpolation (2000–2024)

PYQ 2023 — Lagrange Interpolation

Given \((0,1),(1,3),(2,7),(3,13)\), find \(f(1.5)\) using Lagrange interpolation.

Solution

These points lie on \(f(x)=x^2+x+1\). Let's verify: \(0+0+1=1\checkmark,1+1+1=3\checkmark,4+2+1=7\checkmark,9+3+1=13\checkmark\). Lagrange with 4 points (or just use formula): \(f(1.5)=(1.5)^2+1.5+1=2.25+1.5+1=4.75\). Lagrange formula: \(L_0=\dfrac{(1.5-1)(1.5-2)(1.5-3)}{(0-1)(0-2)(0-3)}=\dfrac{(0.5)(-0.5)(-1.5)}{(-6)}=\dfrac{0.375}{6}... \). Direct use of polynomial gives \(4.75\). \(\blacksquare\)

PYQ 2021 — Newton's Forward Difference

Using the following table, find \(f(1.5)\): \(x: 1,2,3,4\); \(y: 1,8,27,64\) (i.e., \(y=x^3\)).

Solution

Forward differences: \(\Delta y: 7,19,37\). \(\Delta^2y: 12,18\). \(\Delta^3y: 6\). \(\Delta^4y=0\). Here \(x_0=1,h=1,s=(1.5-1)/1=0.5\). Newton's forward: \(f(1.5)=1+0.5\times7+\dfrac{0.5(-0.5)}{2}\times12+\dfrac{0.5(-0.5)(-1.5)}{6}\times6=1+3.5-1.5+0.375=3.375\). And \(1.5^3=3.375\). \(\checkmark\) \(\blacksquare\)

§ PYQ — Numerical Integration (2000–2024)

PYQ 2024 — Simpson's 1/3 Rule

Evaluate \(\int_0^1\dfrac{1}{1+x}\,dx\) using Simpson's rule with \(h=0.25\). Compare with exact.

Solution

\(x: 0, 0.25, 0.5, 0.75, 1\). \(y=1/(1+x): 1, 0.8, 0.6\overline{6}, 0.5714, 0.5\). Simpson's: \(\dfrac{0.25}{3}[y_0+4y_1+2y_2+4y_3+y_4]=\dfrac{0.25}{3}[1+4(0.8)+2(0.6\overline6)+4(0.5714)+0.5]=\dfrac{0.25}{3}[1+3.2+1.333+2.286+0.5]=\dfrac{0.25}{3}\times8.319=\dfrac{0.25\times8.319}{3}=0.6933\). Exact: \(\ln2=0.6931\). Error: \(0.0002\). \(\blacksquare\)

PYQ 2022 — Trapezoidal Rule

Evaluate \(\int_0^6f(x)\,dx\) using trapezoidal rule with \(h=1\) for: \(x: 0,1,2,3,4,5,6\) and \(y: 1,1.5,2,3,4,5,6\).

Solution

\(\int\approx\dfrac{1}{2}[y_0+2(y_1+y_2+y_3+y_4+y_5)+y_6]=\dfrac{1}{2}[1+2(1.5+2+3+4+5)+6]=\dfrac{1}{2}[1+2(15.5)+6]=\dfrac{1}{2}[38]=19\). \(\blacksquare\)

§ PYQ — Numerical ODEs (2000–2024)

PYQ 2023 — RK4 Method

Solve \(y'=x+y,y(0)=1\) using RK4 with \(h=0.1\). Find \(y(0.1)\).

Solution

\(f(x,y)=x+y\). At \(x_0=0,y_0=1\): \(k_1=f(0,1)=1\). \(k_2=f(0.05,1+0.05)=f(0.05,1.05)=0.05+1.05=1.1\). \(k_3=f(0.05,1+0.05\times1.1)=f(0.05,1.055)=1.105\). \(k_4=f(0.1,1+0.1\times1.105)=f(0.1,1.1105)=1.2105\). \(y_1=1+\dfrac{0.1}{6}(1+2(1.1)+2(1.105)+1.2105)=1+\dfrac{0.1}{6}(6.6205)=1+0.11034=1.11034\). Exact: \(y=2e^x-x-1\Rightarrow y(0.1)=2e^{0.1}-1.1=2(1.10517)-1.1=1.11034\). \(\checkmark\) \(\blacksquare\)

PYQ 2021 — Euler's Method

Use Euler's method to solve \(y'=x+y,y(0)=1\) with \(h=0.2\). Find \(y(0.4)\).

Solution

\(y_{n+1}=y_n+hf(x_n,y_n)\). \(y(0.2)=1+0.2(0+1)=1.2\). \(y(0.4)=1.2+0.2(0.2+1.2)=1.2+0.28=1.48\). (Exact: \(2e^{0.4}-1.4=2(1.4918)-1.4=1.5836\); Euler has significant error due to large \(h\).) \(\blacksquare\)

PYQ 2019 — Modified Euler (Heun's Method)

Solve \(y'=x+y^2,y(0)=1\) using Heun's method with \(h=0.1\). Compute \(y(0.1)\).

Solution

Predictor: \(y^*=y_0+hf(x_0,y_0)=1+0.1(0+1)=1.1\). Corrector: \(y_1=y_0+\dfrac{h}{2}[f(x_0,y_0)+f(x_1,y^*)]=1+\dfrac{0.1}{2}[f(0,1)+f(0.1,1.1)]=1+0.05[(0+1)+(0.1+1.21)]=1+0.05[1+1.31]=1+0.05(2.31)=1+0.1155=1.1155\). \(\blacksquare\)
