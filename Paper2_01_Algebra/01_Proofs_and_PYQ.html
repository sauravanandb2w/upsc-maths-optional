Lagrange's Theorem — Proof

If \(H\) is a subgroup of a finite group \(G\), then \(|H|\) divides \(|G|\).

Proof (Coset partition)

Step 1 Define left cosets \(aH=\{ah:h\in H\}\) for \(a\in G\).

Step 2 Cosets partition \(G\): Define \(a\sim b\iff a^{-1}b\in H\). This is an equivalence relation (reflexive: \(a^{-1}a=e\in H\); symmetric: \(a^{-1}b\in H\Rightarrow b^{-1}a=(a^{-1}b)^{-1}\in H\); transitive: \(a^{-1}b,b^{-1}c\in H\Rightarrow a^{-1}c=(a^{-1}b)(b^{-1}c)\in H\)). The equivalence class of \(a\) is \(aH\).

Step 3 All cosets have same size: Map \(\phi:H\to aH\) by \(\phi(h)=ah\) is a bijection (injective: \(ah=ah'\Rightarrow h=h'\); surjective: obvious). So \(|aH|=|H|\).

Step 4 \(G\) is partitioned into cosets, each of size \(|H|\). If there are \(k\) cosets: \(|G|=k|H|\). So \(|H|\mid|G|\). \(\blacksquare\)

Corollaries: Order of any element divides \(|G|\). Every group of prime order is cyclic.

First Isomorphism Theorem — Proof

If \(\phi:G\to H\) is a group homomorphism, then \(G/\ker\phi\cong\text{Im}(\phi)\).

Proof

Let \(K=\ker\phi\). Define \(\tilde\phi:G/K\to\text{Im}(\phi)\) by \(\tilde\phi(aK)=\phi(a)\).

Well-defined: If \(aK=bK\Rightarrow a^{-1}b\in K\Rightarrow\phi(a^{-1}b)=e\Rightarrow\phi(a)^{-1}\phi(b)=e\Rightarrow\phi(a)=\phi(b)\).

Homomorphism: \(\tilde\phi(aK\cdot bK)=\tilde\phi(abK)=\phi(ab)=\phi(a)\phi(b)=\tilde\phi(aK)\tilde\phi(bK)\).

Injective: \(\tilde\phi(aK)=e\Rightarrow\phi(a)=e\Rightarrow a\in K\Rightarrow aK=K=e_{G/K}\).

Surjective: For any \(\phi(a)\in\text{Im}(\phi)\): \(\tilde\phi(aK)=\phi(a)\). \(\blacksquare\)

Define multiplication on \(G/N\): \((aN)(bN)=abN\). Well-defined: If \(aN=a'N\) and \(bN=b'N\): \(a'=an_1,b'=bn_2\). Then \(a'b'=an_1bn_2=ab(b^{-1}n_1b)n_2=ab\cdot m\in abN\) (using \(b^{-1}n_1b\in N\) by normality). So \(a'b'N=abN\). Other group axioms follow from \(G\). \(\blacksquare\)

§ Proofs — Sylow Theory

Sylow's First Theorem — Proof sketch

If \(p^k\mid|G|\), then \(G\) has a subgroup of order \(p^k\). In particular, if \(p^m\mid|G|\) but \(p^{m+1}\nmid|G|\), there exists a subgroup of order \(p^m\) (a Sylow \(p\)-subgroup).

Proof (Action on k-element subsets)

Let \(|G|=p^m\cdot s\) with \(\gcd(p,s)=1\). Let \(G\) act on \(\mathcal{X}=\{S\subset G:|S|=p^m\}\) by \(g\cdot S=gS\). \(|\mathcal{X}|=\binom{p^ms}{p^m}\). One can show \(\gcd(|\mathcal{X}|,p)=1\) (key combinatorial fact). So not all orbits have size divisible by \(p\). Some orbit \(\mathcal{O}\) has \(|\mathcal{O}|\) not divisible by \(p\). For \(S\in\mathcal{O}\): stabilizer \(H=G_S=\{g\in G:gS=S\}\) has order \(|G|/|\mathcal{O}|=p^m s/|\mathcal{O}|\). Since \(p\nmid|\mathcal{O}|\): \(p^m\mid|H|\). Also \(|H|\le p^m\) (by embedding \(H\hookrightarrow\text{bij}(S)\)). So \(|H|=p^m\). \(\blacksquare\)

Sylow's Second Theorem: All Sylow p-subgroups are conjugate
Sylow's Third Theorem: \(n_p\equiv1\pmod p\) and \(n_p\mid m\) — Proof
Proof of Third Theorem

Let \(P\) be a fixed Sylow \(p\)-subgroup. Let \(G\) act on \(\mathcal{S}=\{\text{all Sylow }p\text{-subgroups}\}\) by conjugation. By 2nd theorem, this action is transitive: all are conjugate. So \(n_p=|\mathcal{S}|=[G:N_G(P)]\). Since \(P\le N_G(P)\le G\): \(n_p=[G:N_G(P)]\mid[G:P]=m\). Now let \(P\) act on \(\mathcal{S}\) by conjugation. A fixed point \(Q\in\mathcal{S}\): \(PQP^{-1}=Q\Rightarrow P\le N_G(Q)\Rightarrow PQ\le G\). \(|PQ|=|P||Q|/|P\cap Q|\). If \(P\ne Q\): \(PQ\) is not a Sylow \(p\)-subgroup unless \(P=Q\). The unique fixed point of \(P\) acting on \(\mathcal{S}\) is \(P\) itself. So \(n_p=|\mathcal{S}|\equiv1\pmod p\). \(\blacksquare\)

Maximal Ideal ⟺ Quotient Ring is a Field — Proof
Proof

\((\Rightarrow)\) Let \(M\) be maximal in commutative ring \(R\). Let \(a+M\ne0\) in \(R/M\). Consider the ideal \(M+Ra=\{m+ra:m\in M,r\in R\}\supseteq M\). By maximality of \(M\): \(M+Ra=R\). So \(\exists m\in M,s\in R\) with \(m+sa=1\). In \(R/M\): \((s+M)(a+M)=sa+M=1-m+M=1+M\). So \(a+M\) has inverse \(s+M\). \(R/M\) is a field.

\((\Leftarrow)\) If \(R/M\) is a field: let \(I\supsetneq M\) be an ideal. Then \(\exists a\in I\setminus M\). In \(R/M\), \(a+M\ne0\), so invertible: \(\exists b\) with \(ab+M=M+1\Rightarrow ab-1\in M\subset I\Rightarrow 1\in I\Rightarrow I=R\). So \(M\) is maximal. \(\blacksquare\)

Prime Ideal ⟺ Quotient Ring is an Integral Domain — Proof
Proof

\(P\) is prime iff \(ab\in P\Rightarrow a\in P\) or \(b\in P\). In \(R/P\): \((a+P)(b+P)=0+P\iff ab\in P\iff a\in P\) or \(b\in P\iff a+P=0\) or \(b+P=0\). So \(R/P\) has no zero divisors iff \(P\) is prime. \(\blacksquare\)

Finite Integral Domain is a Field — Proof
Proof

Let \(D\) be a finite integral domain and \(a\ne0\). Consider the map \(\phi:D\to D\) by \(\phi(x)=ax\). Injective: \(ax=ay\Rightarrow a(x-y)=0\Rightarrow x-y=0\) (no zero divisors). Surjective: injective map on finite set is surjective. So \(\exists b\in D\) with \(ab=1\). So \(a\) is a unit. Every nonzero element is a unit: \(D\) is a field. \(\blacksquare\)

PYQ 2024 — Order of Elements in S₄

List all elements of \(S_4\), their cycle types, and orders. How many elements have order 4?

Solution

Cycle types and orders in \(S_4\): (1): \(e\) — order 1 (1 element). (2): transpositions — order 2 (\(\binom42=6\) elements). Show that every group of order 15 is cyclic.

Solution

\(|G|=15=3\cdot5\). Sylow: \(n_5\equiv1\pmod5\) and \(n_5\mid3\Rightarrow n_5=1\). So unique Sylow 5-subgroup \(P_5\trianglelefteq G\). \(n_3\equiv1\pmod3\) and \(n_3\mid5\Rightarrow n_3=1\). PYQ 2020 — Subgroup Generated by Two Elements

Show that \(\mathbb{Z}\) is generated by any two coprime integers \(m,n\).

Solution

\(\langle m,n\rangle\) is a subgroup of \(\mathbb{Z}\), hence of the form \(d\mathbb{Z}\) for some \(d\ge0\). Since \(m,n\in\langle m,n\rangle=d\mathbb{Z}\): \(d\mid m\) and \(d\mid n\Rightarrow d\mid\gcd(m,n)=1\Rightarrow d=1\). So \(\langle m,n\rangle=\mathbb{Z}\). \(\blacksquare\)

PYQ 2018 — Group of Even Integers

Show that the set of even integers forms a group under addition. Is it isomorphic to \((\mathbb{Z},+)\)?

Solution

Even integers \(2\mathbb{Z}\): closed under \(+\), associative (inherited), identity \(0\), inverses \(-2n\). Group. Define \(\phi:\mathbb{Z}\to2\mathbb{Z}\) by \(\phi(n)=2n\). Bijective (injective: \(2m=2n\Rightarrow m=n\); surjective: \(2n\in2\mathbb{Z}\)). Homomorphism: \(\phi(m+n)=2(m+n)=2m+2n=\phi(m)+\phi(n)\). Isomorphism: \(2\mathbb{Z}\cong\mathbb{Z}\). \(\blacksquare\)

PYQ 2015 — Abelian Groups of Order p²

Classify all abelian groups of order \(p^2\) (p prime).

Solution

By fundamental theorem of finitely generated abelian groups: abelian groups of order \(p^2\) are either \(\mathbb{Z}_{p^2}\) (cyclic) or \(\mathbb{Z}_p\times\mathbb{Z}_p\) (elementary abelian). These are the only two, up to isomorphism. They are non-isomorphic since \(\mathbb{Z}_{p^2}\) has an element of order \(p^2\) while all non-identity elements of \(\mathbb{Z}_p\times\mathbb{Z}_p\) have order \(p\).

PYQ 2024 — First Isomorphism Theorem Application

If \(\phi:\mathbb{Z}\to\mathbb{Z}_n\) is defined by \(\phi(k)=k\pmod n\), find \(\ker\phi\) and apply First Isomorphism Theorem.

Solution

\(\phi\) is a ring (and group) homomorphism. \(\ker\phi=\{k\in\mathbb{Z}:n\mid k\}=n\mathbb{Z}\). \(\text{Im}(\phi)=\mathbb{Z}_n\) (surjective). By First Isomorphism Theorem: \(\mathbb{Z}/n\mathbb{Z}\cong\mathbb{Z}_n\). \(\blacksquare\)

PYQ 2023 — Aₙ is Normal in Sₙ

Prove that \(A_n\) (alternating group) is normal in \(S_n\) and find \(S_n/A_n\).

Solution

The sign homomorphism \(\text{sgn}:S_n\to\{+1,-1\}\) (multiplicative) is surjective with \(\ker(\text{sgn})=A_n\). So \(A_n\trianglelefteq S_n\) (kernel of homomorphism). By First Isomorphism Theorem: \(S_n/A_n\cong\{+1,-1\}\cong\mathbb{Z}_2\). Index \([S_n:A_n]=2\). \(\blacksquare\)

PYQ 2024 — Eisenstein Application

Show \(f(x)=x^4+x^3+x^2+x+1\) is irreducible over \(\mathbb{Q}\).

Solution

Substitute \(x\to x+1\): \(f(x+1)=\dfrac{(x+1)^5-1}{x}=x^4+5x^3+10x^2+10x+5\). Apply Eisenstein with \(p=5\): \(5\nmid1\) (leading), \(5\mid5,10,10,5\), \(25\nmid5\). So \(f(x+1)\) is irreducible, hence \(f(x)\) is irreducible over \(\mathbb{Q}\). \(\blacksquare\)

PYQ 2023 — Rational Root Test + Irreducibility

Show \(f(x)=x^3-3x+1\) is irreducible over \(\mathbb{Q}\).

Solution

By rational root theorem: possible rational roots are \(\pm1\). \(f(1)=1-3+1=-1\ne0\), \(f(-1)=-1+3+1=3\ne0\). So \(f\) has no rational roots. Since \(\deg f=3\): no rational roots iff irreducible over \(\mathbb{Q}\). \(\blacksquare\)

PYQ 2022 — Eisenstein for Cyclotomic-type

Show \(p(x)=x^p-p\) is irreducible over \(\mathbb{Q}\) for prime \(p\).

Solution

Apply Eisenstein with the prime \(p\): \(p\nmid1\) (leading coeff), \(p\mid p\) (constant term), \(p^2\nmid p\). All middle coefficients are 0, hence divisible by \(p\). Eisenstein's criterion: \(x^p-p\) is irreducible over \(\mathbb{Q}\). \(\blacksquare\)

PYQ 2022 — Lagrange's Theorem

State and prove Lagrange's theorem: the order of any subgroup \(H\) of a finite group \(G\) divides \(|G|\).

Solution

For any \(a\in G\), the left coset \(aH=\{ah:h\in H\}\). Key facts: (1) \(|aH|=|H|\) (map \(h\mapsto ah\) is a bijection). (2) Two cosets are either equal or disjoint: if \(aH\cap bH\ne\emptyset\), then \(ah_1=bh_2\), so \(b^{-1}a=h_2h_1^{-1}\in H\), giving \(aH=bH\). (3) \(G\) is the disjoint union of all distinct left cosets. If there are \(k\) distinct cosets, then \(|G|=k|H|\), so \(|H|\mid|G|\). The index \([G:H]=k=|G|/|H|\). \(\blacksquare\)

The minimal polynomial of \(i\) over \(\mathbb{Q}\) is \(x^2+1\), irreducible (no real rational roots). So \([\mathbb{Q}(i):\mathbb{Q}]=2\). Basis: \(\{1,i\}\). PYQ 2021 — Algebraic Closure

Define the algebraic closure \(\bar{F}\) of a field \(F\) and state its key properties.

Solution

A field \(\bar{F}\) is the algebraic closure of \(F\) if: (1) \(F\subseteq\bar{F}\) (or \(F\) embeds in \(\bar{F}\)); (2) \(\bar{F}\) is algebraic over \(F\) (every element of \(\bar{F}\) is algebraic over \(F\)); (3) \(\bar{F}\) is algebraically closed: every non-constant polynomial in \(\bar{F}[x]\) has a root in \(\bar{F}\). Equivalently: every polynomial in \(F[x]\) splits completely in \(\bar{F}[x]\). Existence and uniqueness: Every field has an algebraic closure, unique up to \(F\)-isomorphism (Steinitz). Examples: \(\bar{\mathbb{Q}}\) = algebraic numbers; \(\overline{\mathbb{F}_p}\) = algebraic closure of finite field; \(\bar{\mathbb{R}}=\mathbb{C}\). \(\blacksquare\)

PYQ 2020 — Minimal Polynomial of √2+√3 over ℚ

Find the minimal polynomial of \(\alpha=\sqrt{2}+\sqrt{3}\) over \(\mathbb{Q}\) and show \([\mathbb{Q}(\alpha):\mathbb{Q}]=4\).

Solution

\(\alpha=\sqrt{2}+\sqrt{3}\). Then \(\alpha^2=5+2\sqrt{6}\), so \(\alpha^2-5=2\sqrt{6}\), so \((\alpha^2-5)^2=24\), giving \(\alpha^4-10\alpha^2+25=24\), i.e., \(\alpha^4-10\alpha^2+1=0\). So \(m(x)=x^4-10x^2+1\). Irreducibility: check \(m\) has no rational roots (\(\pm1\) fail) and does not factor into two quadratics over \(\mathbb{Q}\): if \(m=(x^2+ax+b)(x^2-ax+c)\) then expanding: \(a=0\) (coefficient of \(x^3\) is 0), \(b+c-a^2=-10\), so \(b+c=-10\), and \(bc=1\), but \(b+c=-10,bc=1\) gives \(b,c=(-10\pm\sqrt{96})/2\notin\mathbb{Q}\). So \(m\) is irreducible of degree 4, and \([\mathbb{Q}(\alpha):\mathbb{Q}]=4\). \(\blacksquare\)

PYQ 2019 — Finite Fields: GF(p^n)

State the classification of finite fields: there exists a field of order \(p^n\) for each prime \(p\) and \(n\ge1\), unique up to isomorphism.

Solution

Existence: The splitting field of \(x^{p^n}-x\) over \(\mathbb{F}_p\) has exactly \(p^n\) elements (the roots of \(x^{p^n}-x\) are distinct — derivative is \(-1\ne0\) — and form a field). Uniqueness: Any field of order \(p^n\) has characteristic \(p\), so contains \(\mathbb{F}_p\). Every element \(\alpha\) satisfies \(\alpha^{p^n}=\alpha\) (multiplicative group has order \(p^n-1\)). So every element is a root of \(x^{p^n}-x\), meaning the field is the splitting field of \(x^{p^n}-x\) over \(\mathbb{F}_p\). Splitting fields are unique up to isomorphism. We write \(\text{GF}(p^n)=\mathbb{F}_{p^n}\). \(\blacksquare\)

PYQ 2018 — Number of Irreducible Polynomials of Degree n over GF(p)

Find the number of monic irreducible polynomials of degree \(n\) over \(\mathbb{F}_p\).

Solution

Let \(N(n)\) = number of monic irreducible polynomials of degree \(n\) over \(\mathbb{F}_p\). Since \(x^{p^n}-x=\prod_{d\mid n}\prod_{f\text{ irred, deg }d}f(x)\) in \(\mathbb{F}_p[x]\), taking degrees: \(p^n=\sum_{d\mid n}d\cdot N(d)\). By Möbius inversion: \(N(n)=\frac{1}{n}\sum_{d\mid n}\mu(n/d)p^d\), where \(\mu\) is the Möbius function. For \(n=1\): \(N(1)=p\). For \(n=2\): \(N(2)=(p^2-p)/2=p(p-1)/2\). For prime \(n=q\): \(N(q)=(p^q-p)/q\). \(\blacksquare\)

PYQ 2017 — Galois Group of x⁴−2 over ℚ Is D_4

State the result that \(\text{Gal}(\mathbb{Q}(\sqrt[4]{2},i)/\mathbb{Q})\cong D_4\) and describe the generators.

Solution

The splitting field of \(x^4-2\) over \(\mathbb{Q}\) is \(L=\mathbb{Q}(\sqrt[4]{2},i)\) (roots are \(\pm\sqrt[4]{2},\pm i\sqrt[4]{2}\)). We have \([L:\mathbb{Q}]=8\). The Galois group \(G=\text{Gal}(L/\mathbb{Q})\) has \(|G|=[L:\mathbb{Q}]=8\). The two generators are: \(\sigma:\sqrt[4]{2}\mapsto i\sqrt[4]{2},\, i\mapsto i\) (rotation of roots, order 4); \(\tau:\sqrt[4]{2}\mapsto\sqrt[4]{2},\, i\mapsto -i\) (complex conjugation, order 2). They satisfy \(\tau\sigma\tau^{-1}=\sigma^{-1}\), so \(G=\langle\sigma,\tau\rangle\cong D_4\). \(\blacksquare\)

PYQ 2016 — Fundamental Theorem of Galois Theory

State the Fundamental Theorem of Galois Theory.

Solution

Let \(L/F\) be a finite Galois extension with Galois group \(G=\text{Gal}(L/F)\). There is an inclusion-reversing bijection (the Galois correspondence): \[\{\text{intermediate fields } F\subseteq K\subseteq L\}\longleftrightarrow\{\text{subgroups } H\le G\}\] given by \(K\mapsto\text{Gal}(L/K)\) and \(H\mapsto L^H\) (fixed field). Under this correspondence: (1) \([L:K]=|H|\) and \([K:F]=[G:H]\). (2) \(K/F\) is Galois \(\iff\) \(H\trianglelefteq G\), and then \(\text{Gal}(K/F)\cong G/H\). (3) Lattice of subfields reverses the lattice of subgroups. \(\blacksquare\)

PYQ 2015 — Solvability by Radicals ↔ Solvable Galois Group

State the theorem connecting solvability by radicals and solvable Galois groups.

Solution

Theorem (Galois): A polynomial \(f(x)\in\mathbb{Q}[x]\) is solvable by radicals (its roots can be expressed using \(+,-,\times,\div\) and \(n\)th root operations) if and only if its Galois group \(\text{Gal}(f)\) (= Galois group of its splitting field over \(\mathbb{Q}\)) is a solvable group. Consequence: The general quintic \(x^5-5x+1\) has Galois group \(S_5\), which is not solvable (since \(A_5\) is simple non-abelian, making the derived series not terminate). Hence the general degree 5 polynomial is not solvable by radicals — no quintic formula exists. \(\blacksquare\)

PYQ 2014 — Extensions of Degree 2 Are Galois

Prove every extension of degree 2 over a field of characteristic \(\ne2\) is Galois.

Solution

Let \([K:F]=2\) and \(\text{char}(F)\ne2\). Pick \(\alpha\in K\setminus F\); then \(\{1,\alpha\}\) is a basis of \(K/F\). The minimal polynomial of \(\alpha\) over \(F\) has degree 2: \(m(x)=x^2+bx+c\in F[x]\). Complete the square: \(\alpha=-b/2+\beta\) where \(\beta=\alpha+b/2\) satisfies \(\beta^2=(b/2)^2-c=d\in F\). So \(K=F(\beta)\) and \(\beta^2=d\). The splitting field of \(x^2-d\) over \(F\) is \(F(\beta)\) (both roots \(\pm\beta\in F(\beta)\) since char\(\ne2\)). A splitting field of a separable polynomial is Galois. Hence \(K/F\) is Galois with \(\text{Gal}(K/F)\cong\mathbb{Z}_2\). \(\blacksquare\)

PYQ 2013 — Normal Extension

Define normal extension and give an example of a non-normal extension.

Solution

An algebraic extension \(K/F\) is normal if every irreducible polynomial \(f\in F[x]\) that has at least one root in \(K\) splits completely in \(K[x]\). Equivalently: \(K\) is a splitting field of some family of polynomials over \(F\). Non-normal example: \(\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}\). The minimal polynomial \(x^3-2\) has one real root \(\sqrt[3]{2}\in\mathbb{Q}(\sqrt[3]{2})\) but the other roots \(\sqrt[3]{2}\omega,\sqrt[3]{2}\omega^2\) (where \(\omega=e^{2\pi i/3}\)) are complex and not in \(\mathbb{Q}(\sqrt[3]{2})\subset\mathbb{R}\). So \(x^3-2\) does not split completely in \(\mathbb{Q}(\sqrt[3]{2})\). \(\blacksquare\)

PYQ 2012 — Separable Extension

Define separable extension and separable polynomial. State when finite fields give separable extensions.

Solution

A polynomial \(f\in F[x]\) is separable if it has no repeated roots in its splitting field (equivalently, \(\gcd(f,f')=1\)). An algebraic element \(\alpha\) over \(F\) is separable if its minimal polynomial is separable. An algebraic extension \(K/F\) is separable if every element of \(K\) is separable over \(F\). Finite fields: Every extension of finite fields \(\mathbb{F}_{p^n}/\mathbb{F}_p\) is separable (and Galois). The Frobenius \(\phi:\alpha\mapsto\alpha^p\) generates \(\text{Gal}(\mathbb{F}_{p^n}/\mathbb{F}_p)\cong\mathbb{Z}_n\). Over fields of characteristic 0 (like \(\mathbb{Q}\)), every algebraic extension is separable (since \(f'=0\) only if \(f=0\) in char 0). \(\blacksquare\)

PYQ 2011 — Cyclotomic Polynomial Φ_n(x)

Define the cyclotomic polynomial \(\Phi_n(x)\) and show \(\Phi_p(x)=1+x+\cdots+x^{p-1}\) is irreducible over \(\mathbb{Q}\).

Solution

\(\Phi_n(x)=\prod_{\substack{1\le k\le n\\\gcd(k,n)=1}}(x-e^{2\pi ik/n})\), the product over primitive \(n\)th roots of unity. It has degree \(\phi(n)\) (Euler's totient) and integer coefficients. For prime \(p\): \(\Phi_p(x)=(x^p-1)/(x-1)=x^{p-1}+\cdots+x+1\). Irreducibility: substitute \(x=y+1\): \(\Phi_p(y+1)=\frac{(y+1)^p-1}{y}=y^{p-1}+\binom{p}{1}y^{p-2}+\cdots+\binom{p}{p-1}\). Apply Eisenstein with prime \(p\): leading coeff 1 (not div by \(p\)), all others \(\binom{p}{k}\) for \(1\le k\le p-1\) are divisible by \(p\), constant term \(\binom{p}{p-1}=p\) not divisible by \(p^2\). So \(\Phi_p(y+1)\) is irreducible over \(\mathbb{Q}\), hence \(\Phi_p(x)\) is irreducible. \(\blacksquare\)

PYQ 2010 — Galois Group of x³−2 over ℚ Is S_3

Solution

PYQ 2009 — Galois Correspondence: Subfields ↔ Subgroups

For the extension \(\mathbb{Q}(\sqrt{2},\sqrt{3})/\mathbb{Q}\), draw the lattice of subfields and corresponding subgroups.

Solution

\(L=\mathbb{Q}(\sqrt2,\sqrt3)\), \([L:\mathbb{Q}]=4\). Galois group \(G=\text{Gal}(L/\mathbb{Q})\cong\mathbb{Z}_2\times\mathbb{Z}_2\) with generators: \(\sigma:\sqrt2\mapsto-\sqrt2,\sqrt3\mapsto\sqrt3\); \(\tau:\sqrt2\mapsto\sqrt2,\sqrt3\mapsto-\sqrt3\). PYQ 2008 — Modules over ℤ Are Abelian Groups

Show that \(\mathbb{Z}\)-modules are exactly abelian groups.

Solution

A \(\mathbb{Z}\)-module \(M\) is an abelian group \((M,+)\) together with scalar multiplication \(\mathbb{Z}\times M\to M\) satisfying the module axioms. But for abelian groups, the action of \(n\in\mathbb{Z}\) on \(m\in M\) is forced: \(n\cdot m=m+m+\cdots+m\) (\(n\) times) for \(n>0\), \(0\cdot m=0\), \(n\cdot m=-(|n|\cdot m)\) for \(n<0\). This is the unique \(\mathbb{Z}\)-module structure on any abelian group, and it satisfies all module axioms. Conversely, any \(\mathbb{Z}\)-module is an abelian group. Hence \(\mathbb{Z}\text{-Mod}=\text{Ab}\) (category equivalence). \(\blacksquare\)

PYQ 2007 — Free Module of Rank n

Define a free module of rank \(n\) over a ring \(R\) and give key properties.

Solution

A free \(R\)-module of rank \(n\) is \(R^n=R\oplus R\oplus\cdots\oplus R\) (\(n\) copies), or equivalently any \(R\)-module with a basis of \(n\) elements (a linearly independent spanning set). Universal property: For any \(R\)-module \(M\) and any set map from a basis \(\{e_1,\ldots,e_n\}\) to \(M\), there is a unique \(R\)-module homomorphism \(R^n\to M\) extending it. Every \(R\)-module is a quotient of a free module. For commutative rings, any two bases of a free module have the same cardinality (invariant basis number property), so rank is well-defined. \(\blacksquare\)

PYQ 2006 — Structure Theorem for Finitely Generated Abelian Groups

State the structure theorem and classify \(\mathbb{Z}_2\oplus\mathbb{Z}_4\oplus\mathbb{Z}\) vs \(\mathbb{Z}_2\oplus\mathbb{Z}_2\oplus\mathbb{Z}_4\).

Solution

Theorem: Every finitely generated abelian group \(G\) is isomorphic to \(\mathbb{Z}^r\oplus\mathbb{Z}_{d_1}\oplus\cdots\oplus\mathbb{Z}_{d_k}\) where \(r\ge0\) (free rank), \(d_1\mid d_2\mid\cdots\mid d_k\ge2\) (invariant factors). PYQ 2005 — Primary Decomposition of Abelian Groups

State the primary decomposition theorem and apply it to classify all abelian groups of order 36.

Solution

Primary Decomposition: Every finite abelian group \(G\) is isomorphic to a direct sum of cyclic groups of prime power order: \(G\cong\mathbb{Z}_{p_1^{a_1}}\oplus\cdots\oplus\mathbb{Z}_{p_k^{a_k}}\). This is unique up to reordering. Order 36 = 4 · 9 = 2² · 3²: The abelian groups of order 36 correspond to partitions of the exponent at each prime: For \(p=2\) (exponent 2): partitions of 2: \((2)\to\mathbb{Z}_4\); \((1,1)\to\mathbb{Z}_2\oplus\mathbb{Z}_2\). For \(p=3\) (exponent 2): partitions of 2: \((2)\to\mathbb{Z}_9\); \((1,1)\to\mathbb{Z}_3\oplus\mathbb{Z}_3\). Combining: \(\mathbb{Z}_4\oplus\mathbb{Z}_9\cong\mathbb{Z}_{36}\); \(\mathbb{Z}_4\oplus\mathbb{Z}_3\oplus\mathbb{Z}_3\cong\mathbb{Z}_4\oplus\mathbb{Z}_3^2\); \(\mathbb{Z}_2^2\oplus\mathbb{Z}_9\); \(\mathbb{Z}_2^2\oplus\mathbb{Z}_3^2\). Four distinct abelian groups of order 36. \(\blacksquare\)
