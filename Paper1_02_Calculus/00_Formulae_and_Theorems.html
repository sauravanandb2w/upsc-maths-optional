§1 · Limits & Continuity

Standard Limits memorise
  • \(\lim_{x\to 0}\dfrac{\sin x}{x} = 1\)
  • \(\lim_{x\to 0}\dfrac{1-\cos x}{x^2} = \dfrac{1}{2}\)
  • \(\lim_{x\to 0}\dfrac{\tan x}{x} = 1\)
  • \(\lim_{x\to 0}(1+x)^{1/x} = e\),   \(\lim_{x\to\infty}\left(1+\dfrac{1}{x}\right)^x = e\)
  • \(\lim_{x\to 0}\dfrac{e^x-1}{x} = 1\),   \(\lim_{x\to 0}\dfrac{\ln(1+x)}{x} = 1\)
  • \(\lim_{x\to 0}\dfrac{a^x-1}{x} = \ln a\)
  • \(\lim_{x\to 0}\dfrac{(1+x)^n - 1}{x} = n\)
Indeterminate Forms → L'Hôpital

Forms: \(\frac{0}{0},\;\frac{\infty}{\infty},\; 0\cdot\infty,\; \infty-\infty,\; 0^0,\; 1^\infty,\; \infty^0\).

Convert \(0\cdot\infty\) to \(\frac{0}{1/\infty}\). For \(1^\infty\): take \(\ln\), use \(\lim e^{f\ln g}\).

§2 · Differentiation & Mean Value Theorems

Differentiation Formulae foundation
  • \(\frac{d}{dx}(x^n) = nx^{n-1}\)  |  \(\frac{d}{dx}(a^x) = a^x \ln a\)
  • \(\frac{d}{dx}(\ln|x|) = \frac{1}{x}\)  |  \(\frac{d}{dx}(\log_a x) = \frac{1}{x\ln a}\)
  • \(\frac{d}{dx}(\sin^{-1}x) = \dfrac{1}{\sqrt{1-x^2}}\)  |  \(\frac{d}{dx}(\cos^{-1}x) = \dfrac{-1}{\sqrt{1-x^2}}\)
  • \(\frac{d}{dx}(\tan^{-1}x) = \dfrac{1}{1+x^2}\)  |  \(\frac{d}{dx}(\cot^{-1}x) = \dfrac{-1}{1+x^2}\)
  • \(\frac{d}{dx}(\sec^{-1}x) = \dfrac{1}{|x|\sqrt{x^2-1}}\)
  • \(\frac{d}{dx}(\sinh x) = \cosh x\)  |  \(\frac{d}{dx}(\cosh x) = \sinh x\)
  • \(\frac{d}{dx}(\tanh^{-1}x) = \dfrac{1}{1-x^2}\),   \(|x|<1\)
Rolle's Theorem

\(f\) continuous on \([a,b]\), differentiable on \((a,b)\), \(f(a)=f(b)\) ⟹ \(\exists\,c\in(a,b)\) with \(f'(c)=0\).

Lagrange MVT ★★★

\(f'(c) = \dfrac{f(b)-f(a)}{b-a}\) for some \(c\in(a,b)\).

Corollaries: (i) \(f'=0\) on \((a,b)\) ⟹ \(f\) is constant.  (ii) \(f'>0\) ⟹ \(f\) strictly increasing.

Cauchy's MVT

\(\dfrac{f(b)-f(a)}{g(b)-g(a)} = \dfrac{f'(c)}{g'(c)}\)  (derivation of L'Hôpital).

Leibniz Rule — nth Derivative of a Product ★★

\[(uv)^{(n)} = \sum_{k=0}^n \binom{n}{k} u^{(k)}\, v^{(n-k)}\]

Analogue of binomial expansion. Useful for \((x^m e^{ax})\), \((x^m \sin bx)\), etc.

§3 · Taylor & Maclaurin Series

Taylor's Theorem ★★★

\[f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x-a)^k + R_n\]

Lagrange Remainder: \(R_n = \dfrac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}\),   \(c\) between \(a\) and \(x\).

Key Maclaurin Expansions memorise exactly
  • \(e^x = 1 + x + \dfrac{x^2}{2!} + \dfrac{x^3}{3!} + \cdots\)
  • \(\sin x = x - \dfrac{x^3}{3!} + \dfrac{x^5}{5!} - \cdots\)
  • \(\cos x = 1 - \dfrac{x^2}{2!} + \dfrac{x^4}{4!} - \cdots\)
  • \(\ln(1+x) = x - \dfrac{x^2}{2} + \dfrac{x^3}{3} - \cdots\),   \(-1
  • \((1+x)^n = 1+nx+\dfrac{n(n-1)}{2!}x^2+\cdots\),   \(|x|<1\)
  • \(\tan x = x + \dfrac{x^3}{3} + \dfrac{2x^5}{15} + \dfrac{17x^7}{315}+\cdots\)
  • \(\sec x = 1 + \dfrac{x^2}{2} + \dfrac{5x^4}{24} + \cdots\)
  • \(\sinh x = x + \dfrac{x^3}{3!} + \dfrac{x^5}{5!}+\cdots\)  |  \(\cosh x = 1 + \dfrac{x^2}{2!}+\dfrac{x^4}{4!}+\cdots\)

§4 · Maxima, Minima & Extrema

First Derivative Test ★★

At critical point \(c\) (where \(f'(c)=0\) or undefined):

  • \(f'\) changes \(+\to-\) at \(c\): local maximum.
  • \(f'\) changes \(-\to+\) at \(c\): local minimum.
  • No sign change: neither (saddle/inflection in 1D).
Second Derivative Test (1 variable)

At \(f'(c)=0\): if \(f''(c)>0\) → local min; if \(f''(c)<0\) → local max; if \(f''(c)=0\) → inconclusive.

Second Derivative Test (2 variables) ★★★

At critical point \((a,b)\) where \(f_x=f_y=0\). Let \(D = f_{xx}f_{yy} - f_{xy}^2\):

  • \(D>0,\; f_{xx}>0\): local minimum.
  • \(D>0,\; f_{xx}<0\): local maximum.
  • \(D<0\): saddle point.
  • \(D=0\): inconclusive — higher order test needed.
Lagrange Multipliers ★★★

To extremize \(f(x,y,z)\) subject to \(g(x,y,z)=0\):

\[\nabla f = \lambda \nabla g\]

i.e. \(f_x = \lambda g_x\), \(f_y = \lambda g_y\), \(f_z = \lambda g_z\), and \(g=0\). Solve simultaneously.

For two constraints \(g=0,\, h=0\): \(\nabla f = \lambda\nabla g + \mu\nabla h\).

§5 · Asymptotes & Curve Tracing

Types of Asymptotes ★★

Vertical: \(x=a\) if \(\lim_{x\to a} f(x) = \pm\infty\).

Horizontal: \(y=L\) if \(\lim_{x\to\pm\infty} f(x) = L\).

Oblique (slant): \(y=mx+c\) where \(m=\lim_{x\to\infty}\dfrac{f(x)}{x}\),   \(c=\lim_{x\to\infty}[f(x)-mx]\).

Asymptotes of Algebraic Curves \(f(x,y)=0\) ★★

Parallel to x-axis: equate coefficient of highest power of \(x\) to zero.

Parallel to y-axis: equate coefficient of highest power of \(y\) to zero.

Oblique \(y=mx+c\): Put \(y=mx+c\) in \(f(x,y)=0\), equate leading coefficients to 0 to find \(m\), then \(c\).

\[\phi_n(m)=0 \text{ gives slopes};\quad c = -\frac{\phi_{n-1}(m)}{\phi_n'(m)}\]

Curve Tracing Checklist
  • Symmetry: about x-axis (replace \(y\to-y\)), y-axis, origin.
  • Intercepts: set \(x=0\) and \(y=0\).
  • Regions where curve doesn't exist (imaginary \(y\)).
  • Asymptotes (vertical, horizontal, oblique).
  • Critical points: \(dy/dx = 0\) (max/min), \(d^2y/dx^2=0\) (inflection).
  • Behaviour as \(x\to\pm\infty\).

§6 · Curvature

Curvature Formulae ★★

Cartesian \(y=f(x)\):

\[\kappa = \frac{|y''|}{(1+y'^2)^{3/2}}, \qquad R = \frac{(1+y'^2)^{3/2}}{|y''|}\]

Parametric \(x=x(t),\, y=y(t)\):

\[\kappa = \frac{|\dot x\ddot y - \dot y\ddot x|}{(\dot x^2+\dot y^2)^{3/2}}\]

Polar \(r=f(\theta)\):

\[R = \frac{(r^2+r'^2)^{3/2}}{|r^2+2r'^2-rr''|}\]

Centre of Curvature (Evolute)

\[\bar x = x - \frac{y'(1+y'^2)}{y''}, \qquad \bar y = y + \frac{1+y'^2}{y''}\]

The locus of centres of curvature is the evolute; the original curve is an involute.

Envelope of a Family of Curves ★★

Family \(F(x,y,c)=0\). Envelope: eliminate \(c\) from:

\[F(x,y,c)=0 \quad\text{and}\quad \frac{\partial F}{\partial c}=0\]

§7 · Integration Techniques

Standard Integrals ★★★ must know
  • \(\int \dfrac{dx}{\sqrt{a^2-x^2}} = \sin^{-1}\dfrac{x}{a}+C\)
  • \(\int \dfrac{dx}{a^2+x^2} = \dfrac{1}{a}\tan^{-1}\dfrac{x}{a}+C\)
  • \(\int \dfrac{dx}{\sqrt{x^2\pm a^2}} = \ln\left|x+\sqrt{x^2\pm a^2}\right|+C\)
  • \(\int \sqrt{a^2-x^2}\,dx = \dfrac{x}{2}\sqrt{a^2-x^2}+\dfrac{a^2}{2}\sin^{-1}\dfrac{x}{a}+C\)
  • \(\int \sqrt{x^2+a^2}\,dx = \dfrac{x}{2}\sqrt{x^2+a^2}+\dfrac{a^2}{2}\ln|x+\sqrt{x^2+a^2}|+C\)
  • \(\int e^{ax}\sin bx\,dx = \dfrac{e^{ax}(a\sin bx - b\cos bx)}{a^2+b^2}+C\)
  • \(\int e^{ax}\cos bx\,dx = \dfrac{e^{ax}(a\cos bx + b\sin bx)}{a^2+b^2}+C\)
Reduction Formulae ★★
  • \(I_n = \int \sin^n x\,dx = -\dfrac{\sin^{n-1}x\cos x}{n} + \dfrac{n-1}{n}I_{n-2}\)
  • \(I_n = \int \cos^n x\,dx = \dfrac{\cos^{n-1}x\sin x}{n} + \dfrac{n-1}{n}I_{n-2}\)
  • \(\int_0^{\pi/2}\sin^n x\,dx = \int_0^{\pi/2}\cos^n x\,dx = \begin{cases}\dfrac{(n-1)!!}{n!!}\cdot\dfrac{\pi}{2} & n \text{ even}\\\dfrac{(n-1)!!}{n!!} & n \text{ odd}\end{cases}\)

where \(n!! = n(n-2)(n-4)\cdots\) (double factorial).

Walli's Formula ★

\[\int_0^{\pi/2}\sin^m x\cos^n x\,dx = \frac{(m-1)!!(n-1)!!}{(m+n)!!}\cdot\begin{cases}\pi/2 & m,n \text{ both even}\\1 & \text{otherwise}\end{cases}\]

§8 · Beta & Gamma Functions

Gamma Function ★★★

\[\Gamma(n) = \int_0^\infty x^{n-1}e^{-x}\,dx, \quad n > 0\]

  • \(\Gamma(n+1) = n\,\Gamma(n)\)  (functional equation)
  • \(\Gamma(n+1) = n!\) for positive integers.
  • \(\Gamma(1/2) = \sqrt{\pi}\)
  • \(\Gamma(1) = 1,\quad \Gamma(3/2) = \dfrac{\sqrt{\pi}}{2}\)
Beta Function ★★★

\[B(m,n) = \int_0^1 x^{m-1}(1-x)^{n-1}\,dx = \frac{\Gamma(m)\,\Gamma(n)}{\Gamma(m+n)}\]

  • \(B(m,n) = B(n,m)\)  (symmetric)
  • \(B(m,n) = 2\int_0^{\pi/2}\sin^{2m-1}\theta\cos^{2n-1}\theta\,d\theta\)
  • \(B(m,n) = \int_0^\infty \dfrac{t^{m-1}}{(1+t)^{m+n}}\,dt\)
Key Beta-Gamma Results ★★
  • \(\int_0^{\pi/2}\sin^{2m-1}\theta\cos^{2n-1}\theta\,d\theta = \dfrac{\Gamma(m)\Gamma(n)}{2\,\Gamma(m+n)}\)
  • \(\int_0^\infty e^{-x^2}\,dx = \dfrac{\sqrt{\pi}}{2} = \dfrac{\Gamma(1/2)}{2}\)  (Gaussian)
  • \(\Gamma(m)\,\Gamma(1-m) = \dfrac{\pi}{\sin m\pi}\)  (reflection formula)
  • \(\int_0^1 x^{p-1}(1-x)^{q-1}\ln x\,dx = B(p,q)\left[\psi(p)-\psi(p+q)\right]\)

§9 · Multiple Integrals

Fubini's Theorem ★★

For continuous \(f\) on a rectangle \([a,b]\times[c,d]\):

\[\iint_R f\,dA = \int_a^b\!\!\int_c^d f(x,y)\,dy\,dx = \int_c^d\!\!\int_a^b f(x,y)\,dx\,dy\]

Order of integration can be exchanged. Useful when one order is easier.

Change of Variables — Jacobian ★★★

\[\iint f(x,y)\,dx\,dy = \iint f(x(u,v),\,y(u,v))\,|J|\,du\,dv\]

where \(J = \dfrac{\partial(x,y)}{\partial(u,v)} = \begin{vmatrix}x_u & x_v\\ y_u & y_v\end{vmatrix}\)

Polar: \(x=r\cos\theta,\,y=r\sin\theta\),  \(|J|=r\). So \(dx\,dy = r\,dr\,d\theta\).

Spherical: \(|J|=\rho^2\sin\phi\). So \(dV = \rho^2\sin\phi\,d\rho\,d\phi\,d\theta\).

Cylindrical: \(|J|=r\). So \(dV = r\,dr\,d\theta\,dz\).

Change of Order of Integration ★★★

Sketch the region. Identify limits for both orders. Rewrite with swapped order.

Typical: \(\int_0^1\!\!\int_x^1 f(x,y)\,dy\,dx = \int_0^1\!\!\int_0^y f(x,y)\,dx\,dy\)

§10 · Areas, Volumes & Surfaces

Arc Length ★★
  • Cartesian: \(L = \int_a^b \sqrt{1+\left(\dfrac{dy}{dx}\right)^2}\,dx\)
  • Parametric: \(L = \int_{t_1}^{t_2}\sqrt{\dot x^2+\dot y^2}\,dt\)
  • Polar: \(L = \int_{\alpha}^{\beta}\sqrt{r^2+\left(\dfrac{dr}{d\theta}\right)^2}\,d\theta\)
Area Formulae ★★
  • Cartesian: \(A = \int_a^b |f(x)|\,dx\)
  • Between curves: \(A = \int_a^b [f(x)-g(x)]\,dx\) where \(f\ge g\)
  • Polar: \(A = \dfrac{1}{2}\int_\alpha^\beta r^2\,d\theta\)
  • Parametric: \(A = \int y\,dx = \int_{t_1}^{t_2} y(t)\,\dot x(t)\,dt\)
Volume of Solids of Revolution
  • About x-axis (Disk): \(V = \pi\int_a^b [f(x)]^2\,dx\)
  • About y-axis (Shell): \(V = 2\pi\int_a^b x\,f(x)\,dx\)
  • Pappus's Theorem: \(V = 2\pi\bar{d}\cdot A\) where \(\bar d\) = distance of centroid from axis, \(A\) = area.
Surface Area of Revolution ★
  • About x-axis: \(S = 2\pi\int_a^b f(x)\sqrt{1+f'(x)^2}\,dx\)
  • Parametric: \(S = 2\pi\int_{t_1}^{t_2} y\,\sqrt{\dot x^2+\dot y^2}\,dt\)

§11 · Functions of Several Variables

Partial Derivatives & Clairaut's Theorem

If \(f_{xy}\) and \(f_{yx}\) are both continuous, then \(f_{xy} = f_{yx}\).

Chain Rule (several variables) ★★

If \(z=f(x,y)\), \(x=x(t)\), \(y=y(t)\):

\[\frac{dz}{dt} = \frac{\partial z}{\partial x}\frac{dx}{dt} + \frac{\partial z}{\partial y}\frac{dy}{dt}\]

If \(z=f(x,y)\), \(x=x(u,v)\), \(y=y(u,v)\):

\[\frac{\partial z}{\partial u} = \frac{\partial z}{\partial x}\frac{\partial x}{\partial u} + \frac{\partial z}{\partial y}\frac{\partial y}{\partial u}\]

Euler's Theorem on Homogeneous Functions ★★★

If \(f(x,y)\) is homogeneous of degree \(n\), then:

\[x\frac{\partial f}{\partial x} + y\frac{\partial f}{\partial y} = nf\]

Second-order extension: \(x^2 f_{xx} + 2xy f_{xy} + y^2 f_{yy} = n(n-1)f\)

Test for homogeneity: \(f(tx,ty) = t^n f(x,y)\).

Implicit Differentiation

If \(F(x,y)=0\), then \(\dfrac{dy}{dx} = -\dfrac{F_x}{F_y}\).

If \(F(x,y,z)=0\), then \(\dfrac{\partial z}{\partial x} = -\dfrac{F_x}{F_z}\),   \(\dfrac{\partial z}{\partial y} = -\dfrac{F_y}{F_z}\).

Taylor's Theorem for \(f(x,y)\) ★★

\[f(a+h,b+k) = f(a,b) + \left(h\frac{\partial}{\partial x}+k\frac{\partial}{\partial y}\right)f\Big|_{(a,b)} + \frac{1}{2!}\left(h\frac{\partial}{\partial x}+k\frac{\partial}{\partial y}\right)^2 f\Big|_{(a,b)} + \cdots\]

Jacobian — Functional Dependence ★★

Functions \(u(x,y)\) and \(v(x,y)\) are functionally dependent iff \(\dfrac{\partial(u,v)}{\partial(x,y)}=0\).

Jacobian: \(J = \begin{vmatrix}u_x & u_y\\v_x & v_y\end{vmatrix}\).   If \(J\ne 0\) at a point, transformation is locally invertible.

\(J(u,v)\cdot J(x,y) = 1\)  (for inverse transformation).

Quick Reference: Coordinate Transformations
  • Polar: \(J=r\), \(dA=r\,dr\,d\theta\)
  • Cylindrical: \(J=r\), \(dV=r\,dr\,d\theta\,dz\)
  • Spherical: \(J=\rho^2\sin\phi\), \(dV=\rho^2\sin\phi\,d\rho\,d\phi\,d\theta\)
  • \(\phi\) = polar angle from z-axis (colatitude), \(\theta\) = azimuthal angle
