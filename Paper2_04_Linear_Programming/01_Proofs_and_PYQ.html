§ Proofs — Fundamental Theorems

Theorem: Optimal Solution at Extreme Point

If an LP has an optimal solution, it has an optimal solution at an extreme point (vertex) of the feasible region.

Proof

Step 1 Let \(\mathbf{x}^*\) be any optimal solution. If \(\mathbf{x}^*\) is an extreme point, done. If not, \(\mathbf{x}^*=\lambda\mathbf{u}+(1-\lambda)\mathbf{v}\) for some \(\mathbf{u}\ne\mathbf{v}\) in the feasible region and \(\lambda\in(0,1)\).

Step 2 Since \(\mathbf{x}^*\) is optimal: \(\mathbf{c}^T\mathbf{x}^*\ge\mathbf{c}^T\mathbf{x}\) for all feasible \(\mathbf{x}\). But \(\mathbf{c}^T\mathbf{x}^*=\lambda\mathbf{c}^T\mathbf{u}+(1-\lambda)\mathbf{c}^T\mathbf{v}\). Since \(\mathbf{c}^T\mathbf{u}\le\mathbf{c}^T\mathbf{x}^*\) and \(\mathbf{c}^T\mathbf{v}\le\mathbf{c}^T\mathbf{x}^*\): we need both \(\mathbf{c}^T\mathbf{u}=\mathbf{c}^T\mathbf{v}=\mathbf{c}^T\mathbf{x}^*\).

Step 3 So all optimal solutions form a convex face of the feasible polytope, which contains at least one extreme point. \(\blacksquare\)

BFS ↔ Extreme Point (Equivalence)

For the standard form LP, a feasible solution is a basic feasible solution iff it is an extreme point of the feasible polytope.

Proof Sketch

(\(\Rightarrow\)) A BFS has \(n-m\) nonbasic variables = 0, so if \(\mathbf{x}=\lambda\mathbf{u}+(1-\lambda)\mathbf{v}\) with \(u_i,v_i\ge0\): \(x_i=0\Rightarrow u_i=v_i=0\). The remaining \(m\) basic variables satisfy \(B\mathbf{x}_B=\mathbf{b}\) and similarly for \(\mathbf{u},\mathbf{v}\). Since \(B\) is invertible: \(\mathbf{u}_B=\mathbf{v}_B=\mathbf{x}_B\). So \(\mathbf{u}=\mathbf{v}=\mathbf{x}\). \(\blacksquare\)

Simplex Optimality Criterion

A BFS is optimal iff all reduced costs \(\bar{c}_j=c_j-\mathbf{c}_B^TB^{-1}A_j\ge0\) for all non-basic \(j\) (for minimization).

Proof

Any feasible direction from BFS: increase nonbasic \(x_j\) from 0. Change in objective: \(\Delta z = \bar{c}_j\cdot\Delta x_j\). If all \(\bar{c}_j\ge0\), no feasible direction decreases \(z\), so current BFS is optimal. If some \(\bar{c}_j<0\): increasing \(x_j\) decreases \(z\), so BFS is not optimal. \(\blacksquare\)

§ Proofs — Duality Theory

Weak Duality Theorem

If \(\mathbf{x}\) is primal-feasible and \(\mathbf{y}\) is dual-feasible (for primal minimize \(\mathbf{c}^T\mathbf{x}\) s.t. \(A\mathbf{x}\ge\mathbf{b},\mathbf{x}\ge0\); dual: maximize \(\mathbf{b}^T\mathbf{y}\) s.t. \(A^T\mathbf{y}\le\mathbf{c},\mathbf{y}\ge0\)), then \(\mathbf{b}^T\mathbf{y}\le\mathbf{c}^T\mathbf{x}\).

Proof

\(\mathbf{y}^TA\mathbf{x}\le\mathbf{c}^T\mathbf{x}\) (since \(A^T\mathbf{y}\le\mathbf{c}\) and \(\mathbf{x}\ge0\)). Also \(\mathbf{y}^TA\mathbf{x}\ge\mathbf{y}^T\mathbf{b}=\mathbf{b}^T\mathbf{y}\) (since \(A\mathbf{x}\ge\mathbf{b}\) and \(\mathbf{y}\ge0\)). Hence \(\mathbf{b}^T\mathbf{y}\le\mathbf{c}^T\mathbf{x}\). \(\blacksquare\)

Strong Duality Theorem

If the primal has an optimal solution \(\mathbf{x}^*\), then the dual also has an optimal solution \(\mathbf{y}^*\) with \(\mathbf{c}^T\mathbf{x}^*=\mathbf{b}^T\mathbf{y}^*\).

Proof (via Simplex)

At optimum of primal simplex: optimal basis \(B\). Set \(\mathbf{y}^*=B^{-T}\mathbf{c}_B\). Then \(\mathbf{b}^T\mathbf{y}^*=\mathbf{b}^T B^{-T}\mathbf{c}_B=\mathbf{c}_B^T B^{-1}\mathbf{b}=\mathbf{c}_B^T\mathbf{x}_B^*=\mathbf{c}^T\mathbf{x}^*\). Dual feasibility: \(A^T\mathbf{y}^*=A^TB^{-T}\mathbf{c}_B\le\mathbf{c}\) follows from the optimality condition \(\bar{c}_j\ge0\) for all \(j\). \(\blacksquare\)

Complementary Slackness Conditions

Primal-dual pair \((\mathbf{x},\mathbf{y})\) are both optimal iff: (a) \(y_i(A\mathbf{x}-\mathbf{b})_i=0\) for all \(i\), and (b) \(x_j(\mathbf{c}-A^T\mathbf{y})_j=0\) for all \(j\).

Proof

Optimality: \(\mathbf{c}^T\mathbf{x}=\mathbf{b}^T\mathbf{y}\). From weak duality proof: \(\mathbf{c}^T\mathbf{x}-\mathbf{b}^T\mathbf{y}=(\mathbf{c}-A^T\mathbf{y})^T\mathbf{x}+\mathbf{y}^T(A\mathbf{x}-\mathbf{b})\ge0+0=0\). Equality iff each non-negative term is zero: \((\mathbf{c}-A^T\mathbf{y})_j x_j=0\) and \(y_i(A\mathbf{x}-\mathbf{b})_i=0\). \(\blacksquare\)

§ Transportation & Assignment

Vogel's Approximation Method (VAM) — Algorithm
  1. Compute penalty for each row/column: (2nd smallest − smallest cost).
  2. Select row/column with largest penalty; assign as much as possible to least-cost cell there.
  3. Delete the satisfied row/column; recompute penalties. Repeat until all allocations done.

VAM gives near-optimal (often optimal) initial BFS — preferred over NW-Corner for UPSC.

MODI (u-v) Method — Optimality Test

For each basic cell \((i,j)\): \(u_i+v_j=c_{ij}\). For non-basic cell \((i,j)\): reduced cost \(\Delta_{ij}=c_{ij}-u_i-v_j\). Solution is optimal iff all \(\Delta_{ij}\ge0\).

Maximize \(Z=5x_1+4x_2\) subject to \(6x_1+4x_2\le24,x_1+2x_2\le6,x_1,x_2\ge0\).

Solution (Full Simplex Tableau)

Standard form: add slack \(s_1,s_2\ge0\). Initial tableau: \(\{s_1,s_2\}\) basic, \(Z=0\).

Iteration 1: most negative reduced cost: \(-5\) for \(x_1\). Ratios: \(24/6=4,6/1=6\). Min ratio = 4; pivot on \(x_1\) entering, \(s_1\) leaving. New basis: \(\{x_1,s_2\}\). After row ops: \(x_1=4,s_2=2,Z=20\). Reduced costs: \(x_2:\bar c_2=4-5(4/6)=4-10/3=2/3>0\). All reduced costs \(\ge0\). Optimal!

Optimal: \(x_1=4,x_2=0,Z=20\). (Check: \(6(4)+4(0)=24\le24\checkmark\), \(4+0=4\le6\checkmark\)). \(\blacksquare\)

Supply: \(S_1=30,S_2=40,S_3=30\). Demand: \(D_1=25,D_2=35,D_3=40\). Cost matrix: \(\begin{pmatrix}3&1&7\\5&8&2\\3&7&1\end{pmatrix}\). Find minimum cost allocation.

§ PYQ — Game Theory (2000–2024)

PYQ 2022 — Saddle Point

Find saddle point of the pay-off matrix \(A=\begin{pmatrix}1&2&-1\\-2&3&2\\4&-3&2\end{pmatrix}\).

Solution

Row minima: Row 1: \(-1\), Row 2: \(-2\), Row 3: \(-3\). Maximin = \(-1\) (Row 1). Column maxima: Col 1: 4, Col 2: 3, Col 3: 2. Minimax = 2 (Col 3). Maximin \((-1)\ne\) Minimax (2). No saddle point — mixed strategy required. \(\blacksquare\)

PYQ 2020 — Mixed Strategy (2×2 Game)

Solve the game: \(A=\begin{pmatrix}1&-1\\-1&1\end{pmatrix}\) (matching pennies).

Solution

No saddle point (maximin = \(-1\), minimax = 1). Mixed strategy: let Player I play Row 1 with prob \(p\). Expected payoff if Player II plays Col 1: \(1p-1(1-p)=2p-1\). If Player II plays Col 2: \(-p+(1-p)=1-2p\). Equate: \(2p-1=1-2p\Rightarrow4p=2\Rightarrow p=1/2\). Similarly \(q=1/2\). Value of game \(=0\). Optimal mixed strategies: both play each option with prob 1/2. \(\blacksquare\)

Solve the assignment problem: Cost matrix \(\begin{pmatrix}9&2&7&8\\6&4&3&7\\5&8&1&8\\7&6&9&4\end{pmatrix}\). Assign 4 jobs to 4 persons to minimize cost.

Solution (Hungarian Method)

Step 1 — Row reduction (subtract row min): \(\begin{pmatrix}7&0&5&6\\3&1&0&4\\4&7&0&7\\3&2&5&0\end{pmatrix}\). Step 2 — Column reduction: Col 1: subtract 3 → \(\begin{pmatrix}4&0&5&6\\0&1&0&4\\1&7&0&7\\0&2&5&0\end{pmatrix}\). Step 3 — Cover zeros with minimum lines. Draw lines through row 2, col 2, row 3, col 4 (4 lines). All zeros covered. Assign: \((1,2),(2,1),(3,3),(4,4)\). Cost: \(2+6+1+4=13\). Check: Hungarian gives optimal. \(\blacksquare\)

PYQ 2017 — Two-Phase Simplex

Minimize \(Z=x_1+2x_2+3x_3\) s.t. \(x_1+x_2+x_3=4\), \(2x_1+x_2=6\), \(x_1,x_2,x_3\ge0\).

Phase II: minimize \(Z=x_1+2x_2+3x_3\) over feasible region found. Reduced costs all \(\ge0\) at this BFS. Optimal: \(x_1=2,x_2=2,x_3=0,Z=6\). \(\blacksquare\)

Maximize \(Z=3x_1+5x_2\) s.t. \(x_1-x_2\le1\), \(x_1+x_2\ge3\), \(x_1,x_2\ge0\).

PYQ 2014 — Sensitivity Analysis

For a maximization LP with optimal tableau, the optimal basis changes if objective coefficient of a non-basic variable changes. State the range of \(c_j\) for which current basis remains optimal.

Solution

For a non-basic variable \(x_j\) with reduced cost \(\bar c_j=c_j-\mathbf{c}_B B^{-1}A_j\ge0\): if \(c_j\) increases, \(\bar c_j\) may become negative, changing the basis. Range: \(c_j\le c_j^*+\bar c_j\) i.e. \(c_j\) can increase by at most \(\bar c_j\) from current value before basis changes. For basic variable \(x_i\): compute new reduced costs for all non-basic variables and find the range where all remain \(\ge0\). \(\blacksquare\)

PYQ 2013 — Revised Simplex

Describe the revised simplex method and state its computational advantage over the standard simplex method.

Solution

Revised simplex maintains only \(B^{-1}\) (not full tableau). Steps: (1) Compute \(\mathbf{y}=\mathbf{c}_B B^{-1}\). (2) For each non-basic \(j\): \(\bar c_j=c_j-\mathbf{y}A_j\). (3) Select entering variable (most negative \(\bar c_j\)). (4) Compute \(\bar A_s=B^{-1}A_s\) (only this column). (5) Ratio test. (6) Update \(B^{-1}\) using elementary row operations. Advantage: only \(m\times m\) basis inverse stored vs full \(m\times n\) tableau — saves memory and operations when \(n\gg m\). \(\blacksquare\)

PYQ 2012 — Integer Programming

Solve the integer LP: Maximize \(Z=x_1+x_2\) s.t. \(3x_1+2x_2\le6\), \(x_1+2x_2\le4\), \(x_1,x_2\ge0\) integers.

Solution

Branch 2 (\(x_2\ge2\)): \(3x_1+4\le6,x_1=0,x_2=2,Z=2\). Both branches give \(Z=2\). Integer optimal: \(Z=2\) at \((1,1)\) or \((0,2)\). \(\blacksquare\)

PYQ 2010 — LP: Economic Interpretation of Dual

Explain the economic (shadow price) interpretation of dual variables in an LP.

Solution

For primal: Max \(\mathbf{c}^T\mathbf{x}\) s.t. \(A\mathbf{x}\le\mathbf{b}\). Dual variable \(y_i^*\) = marginal value (shadow price) of resource \(i\): \(y_i^*=\partial Z^*/\partial b_i\). Meaning: if resource \(b_i\) increases by 1 unit, optimal objective increases by \(y_i^*\). At optimal: \(y_i^*=0\) if constraint \(i\) is not binding (surplus resource has zero value); \(y_i^*>0\) if constraint is binding. Complementary slackness: \(y_i^*(b_i-A_i\mathbf{x}^*)=0\). \(\blacksquare\)

PYQ 2009 — Feasibility of LP

Determine whether the system \(x_1+x_2=4\), \(2x_1+2x_2=6\), \(x_1,x_2\ge0\) is feasible.

Solution

Equations: \(x_1+x_2=4\) and \(2x_1+2x_2=6\Rightarrow x_1+x_2=3\). Contradiction (\(4\ne3\)). System is inconsistent — no feasible solution. LP is infeasible. In simplex: Phase I objective value \(>0\) at termination. \(\blacksquare\)

PYQ 2008 — Degenerate BFS

Define a degenerate basic feasible solution. When does degeneracy occur and how does it affect the simplex method?

Solution

A BFS is degenerate if one or more basic variables equals zero. Occurs when: (a) a constraint passes through a corner point shared by more than \(n\) hyperplanes; (b) during simplex when minimum ratio tie occurs (multiple rows give same minimum ratio). Effect: simplex may cycle (revisit same BFS). Resolution: Bland's rule (always select lowest index entering/leaving variable guarantees no cycling), or perturbation/lexicographic method. In practice, cycling is rare. \(\blacksquare\)

PYQ 2014 — Stepping Stone Method

Describe the stepping-stone method for improving a transportation solution.

Solution

For each non-basic cell \((i,j)\): find a closed loop (alternating horizontal/vertical) through occupied cells starting and ending at \((i,j)\). Assign \(+\theta\) and \(-\theta\) alternately. PYQ 2021 — Degeneracy: Bland's Rule

Explain degeneracy in the simplex method and how Bland's rule resolves it.

Solution

Degeneracy: A basic feasible solution is degenerate if some basic variable equals zero. This causes zero-step pivots (objective doesn't improve), and the simplex method may cycle indefinitely. Bland's Rule: (1) Among all eligible entering variables, choose the one with the smallest index. (2) Among all eligible leaving variables (tied minimum ratio), choose the one with the smallest index. Theorem: Under Bland's rule, the simplex method terminates (no cycling) because it never revisits a basis. Proof: by contradiction — if cycling occurred, there exists a "bad" variable; tracking the last-indexed bad variable leads to contradiction of the selection rule. \(\blacksquare\)

PYQ 2020 — Cycling: Charnes Perturbation Method

Describe the Charnes perturbation method to prevent cycling in the simplex algorithm.

Solution

Add small perturbations \(\epsilon_1,\ldots,\epsilon_m\) (with \(0<\epsilon_m\ll\cdots\ll\epsilon_1\ll 1\)) to the RHS: \(b_i\to b_i+\epsilon_i\). This ensures all degenerate BFS become non-degenerate (unique minimum ratio in each pivot). Since the perturbed problem has no degenerate bases, no cycling occurs. After solving, set \(\epsilon_i\to0\) to recover the original optimal. Equivalently, treat the \(\epsilon_i\) symbolically — ties are broken by the lexicographic minimum ratio test. \(\blacksquare\)

Solution

In Phase I, we minimize \(w=\sum a_i\) (sum of artificials). PYQ 2015 — Sensitivity: Cost Coefficient Range

Given the optimal simplex tableau for max \(Z=c_1x_1+5x_2\), find the range of \(c_1\) for which the current basis remains optimal.

Solution

Let the current optimal basis be \(B\) with \(x_1\) basic (say). The reduced cost of nonbasic \(x_j\) is \(\bar{c}_j=c_j-\mathbf{c}_B^T B^{-1}\mathbf{a}_j\). For the basis to remain optimal (max problem), we need all \(\bar{c}_j\le0\). Changing \(c_1\) affects the reduced costs of all nonbasic variables through \(\mathbf{c}_B\). PYQ 2014 — RHS Ranging

Explain RHS ranging: find the range of \(b_1\) for which the current optimal basis remains feasible.

Solution

At optimality, basis \(B\) gives \(\mathbf{x}_B=B^{-1}\mathbf{b}\ge0\). If \(b_1\) changes to \(b_1+\Delta\), then \(\mathbf{x}_B\to B^{-1}\mathbf{b}+\Delta B^{-1}\mathbf{e}_1\) where \(\mathbf{e}_1\) is the first unit vector. Feasibility requires each component \(\ge0\): \((B^{-1}\mathbf{b})_i+\Delta(B^{-1})_{i1}\ge0\) for all \(i\). Solving: \(\Delta\ge-\frac{(B^{-1}\mathbf{b})_i}{(B^{-1})_{i1}}\) when \((B^{-1})_{i1}>0\) and \(\Delta\le-\frac{(B^{-1}\mathbf{b})_i}{(B^{-1})_{i1}}\) when \((B^{-1})_{i1}<0\). This gives \(\Delta\in[\Delta_{\min},\Delta_{\max}]\), hence the range for \(b_1\). \(\blacksquare\)

PYQ 2013 — Revised Simplex: Eta Factorization

Describe the revised simplex method and explain eta factorization for updating \(B^{-1}\).

Solution

Revised simplex maintains \(B^{-1}\) explicitly, computing only the entering column \(\bar{\mathbf{a}}_j=B^{-1}\mathbf{a}_j\) and objective row entries, avoiding full tableau. Eta factorization: When \(x_r\) leaves and \(x_s\) enters, the new basis \(B'\) satisfies \(B'=B\cdot E\) where \(E\) is an eta matrix (identity with \(r\)-th column replaced by \(\bar{\mathbf{a}}_s/\bar{a}_{rs}\)). So \((B')^{-1}=E^{-1}B^{-1}\). We store a product of eta matrices: \(B^{-1}=E_k^{-1}\cdots E_1^{-1}B_0^{-1}\). Each eta matrix is sparse (one column different from identity), making updates \(O(m)\) per pivot instead of \(O(m^2)\). Periodically refactorize to control numerical error. \(\blacksquare\)

PYQ 2010 — Network Simplex for Transportation

Describe the network simplex method applied to transportation problems.

Solution

A transportation problem is a minimum cost flow on a bipartite graph with supply nodes \(s_i\) and demand nodes \(d_j\). The network simplex maintains a spanning tree (basis) of the network. Each basic feasible solution corresponds to a spanning tree; pivots correspond to adding one arc (entering) and removing one arc (leaving) to maintain a tree. The dual variables \(u_i,v_j\) (node potentials) replace the standard \(y=c_BB^{-1}\). Reduced costs are \(\bar{c}_{ij}=c_{ij}-u_i-v_j\); the entering arc has most negative reduced cost. The leaving arc is determined by the minimum flow on the cycle created. This is the MODI method recast as network simplex. \(\blacksquare\)

PYQ 2009 — Staircase LP

What is a staircase LP? Describe its structure and one application.

Solution

A staircase (or block-angular with linking rows) LP has constraint matrix \(A\) in block-diagonal form with additional linking rows: \(\begin{pmatrix}A_1&A_2&&\\B_1&B_2&\ddots&\\&&\ddots&A_T\\&&&B_T\end{pmatrix}\). Each block \(A_t\) links consecutive time periods. Application: Multi-period production planning — variables \((x_t,s_t)\) are production and inventory in period \(t\); constraints link period \(t\) to \(t+1\) via inventory balance \(s_t=s_{t-1}+x_t-d_t\). The staircase structure allows efficient decomposition (e.g., nested decomposition or Dantzig-Wolfe). \(\blacksquare\)

Solution

At a local minimum \(x^*\) (assuming constraint qualification, e.g., LICQ), there exist multipliers \(\mu_i\ge0\) such that: (1) Stationarity: \(\nabla f(x^*)+\sum\mu_i\nabla g_i(x^*)=0\). Derivation sketch: By the Farkas lemma, if no descent direction satisfies all constraint gradients, then \(\nabla f\) is in the cone of active constraint gradients — this is stationarity. For convex \(f,g_i\): KKT conditions are also sufficient. \(\blacksquare\)

Constraints: (1) Inventory balance: \(I_{it}=I_{i,t-1}+x_{it}-d_{it}\), \(I_{it}\ge0\). (2) Capacity: \(\sum_i a_i x_{it}\le C_t\). (3) Logical: \(x_{it}\le M\cdot y_{it}\) (produce only if set up). (4) \(x_{it}\ge0\), \(y_{it}\in\{0,1\}\). Solve by branch-and-bound or Lagrangian relaxation of coupling constraints. \(\blacksquare\)

PYQ 2013 — Gomory Cutting Plane

Explain the Gomory cutting plane method for solving integer programs.

Solution

Solve LP relaxation. If optimal solution \(x^*\) has a fractional component \(x_i^*=\bar{x}_i\) (non-integer), generate a Gomory cut: from the \(i\)-th row of the optimal tableau, \(\sum_j \bar{a}_{ij}x_j=\bar{b}_i\). Write \(\bar{a}_{ij}=\lfloor\bar{a}_{ij}\rfloor+f_{ij}\) and \(\bar{b}_i=\lfloor\bar{b}_i\rfloor+f_i\) (fractional parts). The cut is \(\sum_j f_{ij}x_j\ge f_i\), which is satisfied by all integer feasible points but not by \(x^*\). Add as constraint (with slack), re-solve LP, repeat. The method terminates in finite steps for pure IPs. \(\blacksquare\)

PYQ 2012 — Integer vs LP Relaxation: Integrality Gap

Define the integrality gap and give an example showing it can be arbitrarily large.

Solution

The integrality gap of an IP is \(\text{IG}=\frac{Z^*_{\text{LP}}}{Z^*_{\text{IP}}}\) (for maximization). Example: Max \(\sum x_j\) s.t. \(\sum_j a_j x_j\le b\), \(x_j\in\{0,1\}\). If all \(a_j=b/n+\varepsilon\) and \(b=n\cdot(b/n)\): LP gives \(Z^*_{\text{LP}}=n\cdot\frac{b}{a_j}\approx n\) (fractional), but IP can only take \(\lfloor b/a_j\rfloor=0\) items: \(Z^*_{\text{IP}}=0\) if \(a_j>b\). The gap can be infinite in pathological cases. For specific problems (e.g., totally unimodular matrices), the gap is 0. \(\blacksquare\)

PYQ 2010 — CPM: Critical Path

A project has activities: A(3), B(5), C(4), D(2) with A→C, A→D, B→D, C→end, D→end. Find project duration and critical path.

Solution

PYQ 2009 — Float: Types and Calculations

Define total float, free float, and independent float for an activity \((i,j)\) with duration \(d_{ij}\).

Solution

Given: \(E_i\)=earliest event time at \(i\); \(L_i\)=latest event time at \(i\); \(d_{ij}\)=duration. Total Float: \(TF_{ij}=L_j-E_i-d_{ij}\). Maximum time activity can be delayed without delaying project. Free Float: \(FF_{ij}=E_j-E_i-d_{ij}\). Delay possible without delaying subsequent activities. Independent Float: \(IF_{ij}=\max(0,E_j-L_i-d_{ij})\). Delay possible regardless of preceding and succeeding activities. Relations: \(TF\ge FF\ge IF\ge0\). Critical activities: \(TF=0\). \(\blacksquare\)

PYQ 2008 — Resource Leveling

Explain resource leveling in project management and its relationship to float.

Solution

Resource leveling: Adjust the schedule (within float constraints) to smooth resource usage over time, avoiding peaks and valleys. Objective: minimize the variance of resource usage per period, or keep usage below a limit. Procedure: (1) Compute float for all activities. (2) Identify resource-critical periods. (3) Shift non-critical activities (those with positive float) to earlier or later times to balance resource demand. (4) Constraint: activities cannot be moved beyond their float without delaying the project. Unlike crashing, resource leveling maintains project duration. \(\blacksquare\)

PYQ 2007 — Crashing: Cost-Time Trade-Off

Explain crashing in CPM: if normal time/cost is (10,200) and crash time/cost is (7,500) for a critical activity, find the cost slope and determine whether to crash.

Solution

Cost slope = \(\frac{\text{crash cost}-\text{normal cost}}{\text{normal time}-\text{crash time}}=\frac{500-200}{10-7}=\frac{300}{3}=100\) per day. Crashing saves 1 day for \$100. Decision: crash if indirect cost savings per day \(>\) cost slope. E.g., if overhead = \$150/day: crash by 3 days saves \(3(150-100)=\$150\) net. Procedure: Crash the critical activity with minimum cost slope first, by 1 day, then recheck critical path (may change). Repeat until no beneficial crashing possible or fully crashed. \(\blacksquare\)

PYQ 2006 — PERT vs CPM

Compare PERT and CPM, highlighting their key differences.

Solution

PERT (Program Evaluation and Review Technique): Probabilistic — activity durations are random variables (beta distribution: optimistic \(a\), most likely \(m\), pessimistic \(b\)). Used for R&D, first-time projects. Focuses on time. CPM (Critical Path Method): Deterministic — activity durations are known. Used for repetitive, well-understood projects. Includes cost-time trade-off (crashing). Both use arrow network; both identify critical path. Key differences: PERT gives probability of completion by a date; CPM gives cost-time optimization. PERT: no crashing; CPM: explicit crashing analysis. PERT: activity-on-arrow; CPM: can use either convention. \(\blacksquare\)

PYQ 2005 — Dynamic Programming: Bellman's Principle

State Bellman's Principle of Optimality and apply it to find the shortest path in a network.

Solution

Bellman's Principle: "An optimal policy has the property that, whatever the initial state and decision, the remaining decisions must constitute an optimal policy with regard to the state resulting from the first decision." Shortest path DP: Let \(f_k(i)\)=minimum distance from node \(i\) to destination \(t\) in \(k\) stages. Recursion: \(f_0(t)=0\); \(f_k(i)=\min_j\{c_{ij}+f_{k-1}(j)\}\). Compute stage by stage from \(t\) backward. At \(k=n-1\) (for \(n\)-node graph): \(f_{n-1}(s)\)=shortest path from source \(s\) to \(t\). Traceback optimal path by recording which \(j^*\) achieved the minimum at each stage. \(\blacksquare\)

PYQ 2004 — Dynamic Programming for Knapsack

Use dynamic programming to solve the 0-1 knapsack: items with values (4,5,3) and weights (2,3,2), capacity \(W=5\).

Solution

Let \(V[i][w]\)=max value using first \(i\) items with capacity \(w\). \(V[0][w]=0\). Item 1 (v=4,w=2): \(V[1][w]=4\) for \(w\ge2\), 0 else. PYQ 2026 Q1(e) — Weak and Strong Duality (10m)

State the weak and strong duality theorems for LPPs. If the primal LPP is unbounded, what can you conclude about the dual? Illustrate with an example.

Solution

Weak Duality Theorem: If \(x\) is feasible for the primal (max) and \(y\) is feasible for the dual (min), then \(c^Tx\leq b^Ty\). No feasible primal solution can exceed any feasible dual solution. Strong Duality Theorem: If either the primal or dual has an optimal solution, so does the other, and the optimal values are equal: \(\max c^Tx=\min b^Ty\). Unbounded primal: If the primal is unbounded (objective \(\to+\infty\)), by weak duality no finite dual feasible solution exists, hence the dual must be infeasible. Example: Maximize \(x_1-x_2\) subject to \(x_1,x_2\geq 0\): take \(x_1\to\infty\), so primal is unbounded. Dual: Minimize \(0\cdot y_1\) (no constraints from RHS = 0) subject to \(y_1\geq 1\) (from \(x_1\) column), \(-y_1\geq -1\Rightarrow y_1\leq 1\) (from \(x_2\) column), \(y_1\geq 0\): requires \(y_1=1\) but also \(-y_1\geq-1\Rightarrow y_1\leq 1\) and \(y_1\geq 1\Rightarrow y_1=1\). Here dual is feasible but check: no primal constraints means dual has no variables — dual is infeasible in the degenerate sense, confirming the rule. \(\blacksquare\)
